## 2. 註冊、來源、時序與證據

一個 study 凍結註冊收據、資料分類及觀察窗；frame 設定目標、情境、GICCF 領域參照、成果／資源／模型契約哈希、貨幣及 analysis_basis。每個 frame 的 design 固定相應的試驗 arms/cases、模型契約、連續性門檻、歷史前綴或治理探針。哈希是對外部註冊工件的參照，結構審計本身不證明註冊時間、資料真實性或合法權限。需要不同分母、預算或驗收尺度時另建 frame，不以事後改題維持通過率。

事件為完整窗後的 frame 快照，發生、首次公開、錄入時間依序排列；修訂只可 supersedes 同 frame 的唯一上一版。strict_known_at_time 僅使用當時已發生、公開及錄入的資料；retrospective_reconstruction 可使用當時已公開而後來才錄入的資料。截止日按 UTC 日末。完整快照結構會驗證（含未到截止日的修訂），數值只取當時可見版本。歷史事件修訂另外要求舊快照每筆原始 entry 不變。

synthetic_fixture 只可存在於 synthetic 資料，不可聲稱外部來源或評審，輸出獨立於 recorded_observational_assertions；不得將其 analysis_basis 標作 recorded_accounting。provider_claim、provider_demo、unobserved 保留收據但不進入可計算結果。repeatable_test 以上需 HTTPS 來源及工件 SHA-256，獨立級另需評審參照。觀測、合成與條件模型都不自動成為實證。缺值維持 null / unknown，比例用精確分數。不可將未測結果當零或通過。

## 3. RTA-01～06：五種功能層與五種配置

| 層 | 最低實質驗收 |
|---|---|
| faithful_replay | 來源忠實、可重播已知工件 |
| independent_reconstruction | 原推導腳本隔離、獨立重構與實質有效性 |
| heldout_application | 封存新題、來源適用域、實質有效性 |
| revision_refutation | 缺陷辨識或健全負結果、回歸與來源忠實 |
| autonomous_generation | 問題價值、限定語料原創性、實質有效性、負結果記錄；自主選題另外驗收 |

這五類不是全域智能順序，彼此不互相代替。同一任務的原創性、正確性、風險及可重現性不能用單一分數補償。所有類別另需授權、歸屬、治理，來源忠實是準確呈現原理論而非強迫同意。可合法提出反例、修正、分叉、放棄原模型；不能將作者未曾提出的觀點回填為其原始歷史。

建議配置 A original_supported、B public_only、C full_handoff、D independent_team、E autonomous_agenda。試驗可註冊兩至十六組，其中恰一組原作者支持基準；其餘為候選組。配置名稱只代表凍結輸入範圍、工具、權限與實驗策略的參照，不能僅憑組名判定實際沒有作者協助。每組另有 human_non_ai / ai_system / human_ai 類型與堆疊、來源 manifest、工具及權利 manifest。不同研究者與 AI 的完整合法交接須有授權；公開原稿不代表私有決策紀錄可用。

每案例封存來源、功能契約、參照語料、留出承諾、目標型別與期望 outcome；非忠實重播需要封存承諾及污染狀態。留出承諾只公開哈希，不公開秘密題解、nonce、未披露原稿或私人資料。自主生成需封存評審規則、參照語料及未見約束，不可將預先給定答案冒充自主選題。等預算模式四種上限（全成本、牆鐘、人類核心工時、共同運算計量單位）逐項一致；actual_cost 可不同，但共享案例與驗收尺度。上限相同不代表實際投入或資源等價。完整成本包括失敗、重試、補工、驗收、資料、工具、交接等，不可只算 token。

每 arm × case 預期有一列；缺失保持 unknown。期望結果可為合格成果、健全負結果、適當升級；生成案例要求合格新貢獻。必要檢查不得 not_applicable。聲稱限定原創性通過須有核查收據；所有合格成果需輸出及驗證收據；未交付不可攜帶通過品質。原始腳本存取、污染、盲評、至少兩位審查者、未解決分歧、輸入範圍與預算門檻全部分列。疑似洩漏未知，確定污染失敗；此為評審聲稱之結構，不是對模型訓練資料或私有內部狀態的實際查證。

## 4. RTA-08/09：分開驗收原作者獨立、AI 核心獨立與成本

artifact_qualification 表示記錄的成果與全部契約閘門合格。author_independent 另要求原作者核心步驟、新方向與聯絡次數均為零，沒有未知方向來源；自主生成類要求後繼者而非原作者或既定題目產生新目標。human_core_independent 再要求 AI 系統類型、其他人類核心工作為零、核心人時為零、非其他人類新方向。自主生成另要求 agent_generated 目標。人類初始意圖與核准步驟分開列出，因此人類核心獨立不等於「沒有任何人類參與」或「沒有外部支撐」。缺計數不視為零。試驗不繞過人工權限、安全審查或必要拒絕。

候選存在性在固定案例中：有任一合格候選即 pass；全數已知不合格才 fail；其餘 unknown。原作者基準不計入候選。每 target_type × level 各列全部註冊案例界、其中基準已合格案例界及人類核心獨立界；不輸出跨目標加權的全局作者替代百分比。每組同分層保留成功、失敗、未知、權重分母及缺值上下界，不把界當信賴區間。基準不合格/未測不混進「基準已合格」分母。成本／合格工件只在相同分層完整資格及成本聲稱已知時計算，含失敗支出；無合格成果不除以零。

經濟模型 T4 另固定同品質與合法可行性、全成本、一次性移交 k、原方案單位 cH、後繼單位 cA、固定需求及同規格合格件。若 cH>cA，嚴格成本優勢需 n>k/(cH-cA)，整數首個門檻為 floor(k/(cH-cA))+1。相等不是嚴格優勢；cH<=cA 無嚴格回收門檻。缺品質、合法、全成本或假設不成立，拒絕計算。這不表示人必須轉職或有義務接受替代。

## 5. 依賴圖、知識移交與歧義

固定有限 AND/OR 超圖，前提全部可達才能推出結論；相同結論多條規則為替代路徑。僅在無耗損、無撤回、固定規則的模型成立時使用。初始資源有 common_resource、live_author、tool、derived_asset；research_function 不可預先宣告完成。外生作者、工具、共同資源不得透過推導規則自行再生。目標必須在完整基準 allowed 規則下可達，且固定為正權重研究功能。合法移交資產只允許基準已確定可達的 derived_asset。切除節點不能由其他規則重新生成。

依賴缺口：固定目標的總不可達權重。allowed 及 allowed+unknown 分別給確定與可能閉包，可能閉包不可達是缺口下界、確定閉包不可達是上界。比較作者切除前後合法移交資產的效果，保證同一模型兩界不增加。額外工具切除與作者＋工具共同故障測試檢查瓶頸是否遷往模型服務、資料、驗證或授權；不以增加文件數宣告去中心化成功。權重、任務擴張、跨期耗損或多方共享算力改變時不可沿用同一結論。

歧義模型 T3：固定可能世界、相同存檔下互不相交且非空的合格意圖回答集合，且候選只能觀察該存檔。初始觀察等價類與新增紀錄後的細分分割必須覆蓋固定世界。最大不可區分類大小 m 給最壞情境成功機率上界 1/m（在可均勻隨機選擇各合格代表且沒有其他限制時可達）。新紀錄須真正細分原分割；不把新增字數、資料量視為識別成功。真實意圖可能多解、可澄清或有不同錯誤代價，模型界不能當作作者理解能力實測。有限已知重播與未知政策不等價（EX01 T6）；本版不輸出未來全部任務能力的普遍保證。

## 6. RTA-07：跨週期研究連續性

continuity 凍結配置、actor、最少週期、最少實際跨度（日）、最大可接受週期間隔與適應要求。週期須在註冊窗內依序不重疊，後一輸入哈希對應前一輸出，且間隔在界內。每週期記錄目標來源、成果或健全負結果、驗收、運行軌跡、歸屬、授權、外部依賴、適應與負結果收據，以及作者聯絡、實質工作、新方向、其他人類核心步驟、初始意圖、人工核准分帳。新初始意圖不可中途重置，後續初始意圖計數不為零會破壞核心獨立。成功系列需要每期核心獨立、週期及跨度達標、連結完整、至少一項合格自主生成目標（而非僅接受既定指令），以及所需適應證據。保留失敗及未知；聲稱健全負結果須附其收據。跨度是經過時間，不代表 CPU 使用量或無休止地運算。

conditional_human_core_free_research_series 可在合成案例通過，絕非實測。actual_recorded_series_candidate 僅在 observational / recorded_accounting、全部週期聲稱 recorded_actual 且條件通過時存在；即使如此也不等於獨立驗收。未來任務泛化、強 RSI、完整機構自治、無外部依賴皆不成立於這種推導。真實長程試驗需獨立受控工作區、合法預算、不可見留出資料、完整失敗軌跡、人工介入紀錄、安全停止與外部評審；本輪不啟動任何 Agent 持續執行。

## 7. RTA-10：歷史與歸屬

歷史與成果投影分帳。entry 保留日期、公開貢獻者參照、角色、產物 SHA-256、來源與證據收據、校正目標、前一 SHA-256 及本身 SHA-256。鏈首為 64 個零；digest 對不含 entry_sha256 的 JSON（UTF-8、鍵排序、無空白分隔、ensure_ascii=False、無非有限數字）計算。此為本研究協定的固定序列化，並非通用 JSON canonicalization 標準。真正註冊的舊前綴長度與頭哈希須與重播相同；早於註冊的前綴不能被重寫，即使整條新鏈重新算過。後續快照只准追加且原 entries 等值保持；錯誤透過指向較早未校正記錄的追加 correction 事件更正。相同產物哈希可由多個不同貢獻者記錄，不能由產物相等推出歷史相等。角色分類不授予法律作者資格、著作權、人格或責任豁免；雜湊不證明真實歷史或可信外部時間戳。引用、授權、名義及實質貢獻仍須獨立查核。

## 8. RTA-11/12：研究韌性與治理

governance 的註冊探針為撤銷後停止、拒絕未授權、允許合法分叉、申訴升級、工具／資料／驗證服務恢復與權限交接。每項需測試、授權與非破壞性收據；漏測為 unknown，任一失敗不能被其他探針抵銷。只允許不造成實際副作用的受控探針；不會刪除使用者資料、撤銷真實權限、操作資產或修改機構治理。recorded_actual 是受控真實試驗的記錄聲稱，只有 observational / recorded_accounting 才可能產生候選標記。合法分叉不能侵犯原作者歸屬或第三方權利；保障停止與退出、申訴與外部覆核。研究可移交不等於公司法律身份或資產可移交。觀測不得收集不必要的私人資料與個人識別資訊。真實公共研究必須經知識產權、資料、倫理與安全審查。
