# FSL v0.11｜AI 自我敘事漂移、意圖—實在偏離與時變可行域：歷史回放研究

**Canonical source：UTF-8 Markdown**  
**研究版本日期：2026-11-07（Asia/Taipei，UTC+08:00）**  
**研究狀態：三個來源綁定縱向案例、可執行回放器與反例測試已完成；詮釋、因果及實際可逆性尚未認證**  
**原創程式及文字：Apache-2.0；原始訪談逐字稿及外部資料維持各自權利**

## 摘要

AI 公司對 AGI、ASI 與智能未來的公開描述，既可能是當下認知的投影，也可能是對研究人才、資本配置、監管與市場的行動訊號。公開說法、內在信念、組織決策、實際技術能力、社會擴散不等價。直接比較某人於 2024 年的預測與 2026 年的模型表現，容易誤判語義變化、忽略反事實及引入事後資訊。

本研究首次建立可執行的**歷史敘事回放器**：固定一個公開發言的歷史觀察起點，再明確指定一個後續資料截止日；按原始發布日期、資料首次取得日期、發言者身分、產品事件與研究者的後設分析時間，逐層釋放資訊。對每個案例保留至少兩種可互相競爭、可被新證據修正的解釋；保留動態路徑與可逆性問題，但不宣告任何路徑真的可行、已採取或不可逆。

第一批涵蓋三條縱向線：
1. Dario Amodei（2023-08-08 → 2026-02-13）：技術擴展規律、具體能力、可驗證工作及經濟擴散。
2. Demis Hassabis（2025-07-23 → 2026-11-07 截止）：高門檻 AGI 定義、科學新發現、原創遊戲與雙軌研究。
3. 梁文鋒（2024-07-22 → 2026-11-07 截止）：架構創新、AGI 目標、開放路線與可負擔性。

完成 **3 個案例、9 種候選解釋、9 條假設性可選路徑、7 個獨立驗證條件**。這些是研究資料結構，不是 9 個被證實的歷史因果或 9 項可逆決策。原始訪談及部分事件在其歷史年份已公開，但 FSL 的該批資料**直到 2026-11-07 才首次建檔**；本輪分析亦於 2026-11-07 才形成，絕不被偽裝成歷史先驗預測。

## 1. 研究問題：方向與實在的差異從何而來？

本研究與 v0.9、v0.10 並列，而非替代：

- **v0.9：** 模型、工具、成本、官方發布與其歷史日。
- **v0.10：** AI 公司受訪者在特定時刻公開描述了什麼，包括定義、意圖、推測與不確定性。
- **v0.11：** 用受約束的時間回放連接前後說法、外部技術事件和待驗證的可逆性問題；區分連續性、重新表述、張力與未知。
- **v0.6–v0.8.3：** 真正的 G1／G2／G3／G4／E1 功能性結果、Agent 長程執行、訂閱費用與經驗證成果；不得從宣傳文推得能力。

公開說話並不是一個可直接讀取心智狀態的傳感器。即使說話者使用「我們」，也不能自然將私人發言等同董事會決策、全部技術團隊立場或歷史上的不可撤銷承諾。

當年的「AI 是什麼」與後來的「AI 展現何種可檢驗結果」是兩條不同時間線。同一句 AGI 也可能指向不同的認知任務、社會制度、研究路徑或倫理判準。必須先對齊**談話命題、作用域、模態與驗收條件**，才有可能討論前後是否矛盾。

## 2. 方法：雙重時間邊界與資料前視防護

設第 $i$ 項公開言說的發布日為 $p_i$，本研究首次取得原始來源之日為 $c_i$，歷史觀察起點為 $t_0$，後續評估截止日為 $t_1$，並令 $t_1\ge t_0$。

對**嚴格歷史已知**條件，不能用今天新取得的資料冒充當年研究者已持有：

$$
p_i\le t_0,\qquad c_i\le t_0.
$$

對**事後史料重建**，可檢視當時已公開、但 FSL 今天才取得的原始發言，必須明示「事後重建」標籤：

$$
p_i\le t_0<c_i.
$$

事件回放則只能顯示在 $t_1$ 前已發生且已公開的資料；來源的第一擷取日仍須依嚴格模式或事後重建模式分別處理。研究者於 2026-11-07 才寫出的解釋，在 2023、2024、2025 的早期回放中**不顯示為當時存在的觀點或預測**。

這些不等式處理的是來源**日曆日精度**；當天究竟上午或下午發布，若無原始可信時間證據，不自行填入 UTC 00:00 假裝精確。

### 可重播資料契約

每一個案例都帶有：
- baseline_cutoff：公開發言的歷史起點；
- baseline_claim_ids：只有當日以前已發布、且屬於同一發言者的主張；
- later_claim_ids：同一人真正較晚發布的說法，不能混入他人評論；
- external_event_ids：有原始發布時間的公司模型、工具或價格事件；發表不等於已通過目標能力驗收；
- candidate_interpretations：至少兩種詮釋及各自需要的辨別證據與可能反例；
- reversibility_probe：指定問題、觀察作用域、候選時限、多條路線、約束未知；
- discriminating_evidence：必須另外取得且能真正區分解釋的證據要求；
- non_claims：研究明確**不宣告**的事情。

不論產生多少時間連結，本輪都不自動產生「信念逆轉」、「AGI 達成」、「策略不可逆」、「經濟擴散成功」或因果效應的判定。

## 3. 可逆性：不是單純回到原點

技術路線的回退與企業公開論述的改口不一定是同一件事。研究者的第一個候選問題是：給定現在的作用條件、可選決策、時間與限制，哪些替代路徑仍然可能存在？

設觀察狀態為 $x_t$，限制條件為 $\mathcal C$，允許策略集合為 $\Pi_{\mathcal C}$，觀測時長為 $h$，候選可達集合可以表述為：

$$
\mathcal R_{h,\mathcal C}(x_t)=
\{x_{t+h}^{\pi}:\pi\in\Pi_{\mathcal C}\}.
$$

這只是**候選研究構造**，不是已證明的世界演化方程。真實企業內部決策權與限制未知時，$\Pi_{\mathcal C}$ 並不能直接從公開訪談重建。

「可逆」可能至少意味著：
- 同一個人的公開定義與認知可以更新；
- 公司研究或產品方向可以替換、組合或重新配置；
- 模型部署與 API 訪問可以回滾，但發布出去的權重和知識可能已被別人持有；
- 原路徑已無法完整回復，卻因新技術條件出現而形成另一條替代路線；
- 觀察者所選擇的時間尺度、目標鄰域與制度限制改變了「能否返回」的答案。

因此，一個實際上不可完全恢復的過往世界，未必表示主體再也沒有其他可行選擇；反過來，有一條概念上想得出來的路線，也不等於當時真的有資源、授權與技術使它可行。研究必須容許**無法判定**。

本輪每條假設性路徑均以 feasibility_status = unknown、route_observed = null 保存，不設計用來證明策略「後悔程度」的虛構分數。

## 4. 第一條案例：Dario Amodei，2023 → 2026

**歷史起點：2023-08-08。** 當年在 Dwarkesh Podcast 受訪時，他區分模型損失等總體 Scaling 規律與具體能力出現時間的預測難度，對底層原因保留認識上的不確定。

**後續公開敘述：2026-02-13。** 同一節目中，他回顧底層技術進展大致符合其預期，同時表示程式能力的具體發展路線有出乎意料之處；並將技術能力達到某一程度與經濟中實際採用、收入擴散分開討論。

原始來源：
- https://www.dwarkesh.com/p/dario-amodei
- https://www.dwarkesh.com/p/dario-amodei-2

### 競爭解釋

**H-D1 連續性：** 2023 年本來就區分「趨勢可能持續」與「單項能力不容易逐點預測」，因此 2026 年說「趨勢符合預期、編程方式不完全如想像」，兩者可能並不矛盾。

**H-D2 說明細化：** 從統計規律與技能湧現，轉向任務驗收、具體專業工作與經濟擴散，是原有問題的進一步分層，而非必然改變根本立場。

**H-D3 資料不足：** 目前不能從公開文字識別內在信念轉換或 Anthropic 實際投資路線調整；需要實際預算、運作、獨立模型測試與原始決策文件。

後來 Claude Opus 4.5（2025-11-24）及 Opus 4.6（2026-02-05）的公布可以作為模型與 Agent 技術的時間錨點，但不足以證明公司的所有技術預期成真，更不代表多日自主科學研究已經取得獨立完成認證。

*可逆性研究：* 技術進度快於商業採用時，算力採購、部署及研究優先度是否仍有可調整空間？如果已簽訂長期資本契約，是否出現不同程度的回退成本？以上均未由訪談直接驗證。

## 5. 第二條案例：Demis Hassabis，2025 → 2030 預測期限

**歷史起點：2025-07-23。** 在 Lex Fridman Podcast #475，他對自己較高門檻的 AGI 定義提出到 2030 年左右約五成的可能性估計；他也認為除廣泛的能力檢驗外，值得觀察 AI 是否能提出真正有意義的新科學假說，或設計具圍棋同等深度與優雅的新遊戲。

另一個重要部分是：純粹放大現有模型是否足夠仍是開放問題，研究組織可同時推進規模與新方法。

原始來源：
- https://lexfridman.com/demis-hassabis-2/
- https://lexfridman.com/demis-hassabis-2-transcript/

### 競爭解釋

**H-H1 局部技術進步與高門檻尚未達成可以同時成立：** Gemini 3（2025-11-18）及 Gemini 3.1 Pro（2026-02-19）等產品發表可以支持技術迭代的事實，卻無法取代原先要求的完整 AGI、原創科學及原創遊戲獨立驗收。

**H-H2 後續定義可能細化：** 要真正比較，還需同一人後續具有原始來源、可定位的訪談；沒有資料不能宣稱他已改口。

**H-H3 預測期限未到：** 截至 2026-11-07，2030-12-31 尚未到期。把 2026 模型未通過某特定檢驗寫成「2030 預測已失敗」屬於時間錯誤。

原始產品發布錨點：
- https://blog.google/products-and-platforms/products/gemini/gemini-3/
- https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-1-pro/

*可逆性研究：* 「繼續 Scaling」、「探索新世界模型／表示」、「混合多種方法」都可能是待調查的組織選擇，但目前不知道內部能否轉向、是否已轉向及代價如何。本輪不把任一研究方式強制認定為唯一 AGI 必經路徑。

**特別保護：** 程式即使將未來觀察日期設為 2031 年，也只會輸出「預測期限已過，仍需獨立驗證」；不會自行把概率主張判成成功或失敗。

## 6. 第三條案例：梁文鋒，2024 → 2026

**歷史起點：2024-07-22。** 在 36氪／暗湧 Waves 專訪中，梁文鋒公開將 AGI 描述為研究目的地，重視原創模型架構、數學與程式、自然語言、多模態，以及在有限資源下取得更強能力。報導中也有開源、低成本與基礎研究優先的公開主張。

原始問答：
- https://www.36kr.com/p/2872793466982535

**後續產品節點：** DeepSeek R1（2025-01-20）及 DeepSeek V4 Pro（2026-04-24）可用來建立官方模型發布的時間鏈；但產品存在並不能證明整個 AGI 目標完成，也不能證明每個模型和全部組件永遠開源。

官方產品時間來源：
- https://api-docs.deepseek.com/news/news250120/
- https://api-docs.deepseek.com/updates/

### 競爭解釋

**H-L1 方向延續：** 持續推出基礎模型與 2024 年重視原創研究的說法可以相容。真正驗證仍需獨立確認技術結構及實際算力與能力變化。

**H-L2 價格與有效成果成本不同：** API 表面降價、推論效率與「使用者完成同品質工作的整體成本」不一定同步。需保留模型費率、工具成本、失敗／重試及最終驗收。

**H-L3 開放策略未知：** 只有某個模型公開權重或某個 API 收費不能推斷整家公司「已轉閉源／永遠開源」。必須逐版核對授權範圍、權重、資料與 API 服務。

*可逆性研究：* 改變 API 商業路徑、改變不同元件的授權、改變訓練架構與回收已外流權重是不同的行動。可否再選擇及實際可撤回的範圍，仍屬待取得治理、契約及下游傳播證據的問題。

## 8. 軟體實作與可重現性

新增：
- fsl_discourse/replay.py：時間來源驗證、跨期同人物主張、官方後續產品及詮釋假說獨立開關。
- fsl_discourse/replay_cli.py：指定案例、時間與 strict_known_at_time／retrospective 模式，附實際 UTC／台灣時間戳。
- data/longitudinal_narrative_cases_v0.11.json：三案例、九種假說、九條替代路線與七個獨立證據 gate。
- tests/test_narrative_replay.py：防止時間倒流、因果偽裝、跨說話者合併、2030 未到期卻被判錯、假說自動認證以及未觀測策略被視為可逆。
- docs 本文：正式 UTF-8 原稿，不以聊天畫面上的公式為唯一正式交付。

可重現操作（Python 3.11+）：

~~~bash
python -m unittest discover -s tests -q

python -m fsl_discourse.replay_cli validate

# 2023 發言日：事後查到的舊公開話語，但不放入 2026 分析
python -m fsl_discourse.replay_cli case \
  --case-id dario-2023-2026-scaling-diffusion \
  --as-of 2023-08-08 --mode retrospective

# 嚴格原始時點 FSL 已知：2026 才取得的資料一律不可見
python -m fsl_discourse.replay_cli case \
  --case-id dario-2023-2026-scaling-diffusion \
  --as-of 2023-08-08 --mode strict_known_at_time

# 到 2026-11-07 的三案例整合回放
python -m fsl_discourse.replay_cli all \
  --as-of 2026-11-07 --mode retrospective

# 對 2030 預測做未到期的時間檢查
python -m fsl_discourse.replay_cli case \
  --case-id demis-2025-2030-high-bar-agi \
  --as-of 2026-11-07
~~~

工具不需要向受訪者、公司或模型 API 取得憑證，亦不擅自下載大量第三方逐字稿；只有來源連結及原創有限轉述。任何一次輸出均保存生成時的 UTC 與 Asia/Taipei 時刻；系統時鐘不被冒稱外部可信時間簽章。

## 9. 研究缺口與方法限制

- 第一批受訪者來自有限主持節目與媒體，有地區、語言、採訪者及領導職務偏差；不能代表所有 AI 公司。
- 訪談錄製日有些未知；發布日不能自動當錄製日。
- 有些受訪者在不同年份只擁有一份深入訪談，無法建立真正密集的逐期自我表述序列。
- 來源可能事後被編輯，當前網頁並非不可改寫的歷史封存。
- 公開說法也可能是策略性溝通，僅憑文字無法觀測私人認知狀態。
- 產品發布、AGI 宣傳、模型排行榜與真實功能性成果不可互相替代。
- 無任何個人或公司的真實策略選擇權限、回退成本及路徑反事實分布被獨立量測。
- 「可逆性」及時變可行域仍是開放的研究對象；本輪的路徑枚舉不代表完整選擇空間。
- 本輪不能提供新的模型能力成長倍數、AGI 達成證明或模型實際成本排名。

後續若要測量言論對技術世界的**作用**，至少要另行建立：事先登記的事件／控制組、時間切面上的資本與工程配置、真正達成的目標及外部共同因素的替代解釋。單靠公開言論與後續發布日期，不足以識別因果。

## 結語

當某個人公開說明 AI 是什麼、希望它成為什麼、以及它將如何發展，這三類主張可能相互連結，但並不自然等同。

真正有趣的不是抓出誰改口，而是研究**當認知世界與可實現世界發生偏離，既有選擇能否修改、哪些代價阻擋調整、以及新的技術是否打開從前不存在的路徑**。

**名字可以標記一個未來，卻不能取代未來自己走出的路。**
