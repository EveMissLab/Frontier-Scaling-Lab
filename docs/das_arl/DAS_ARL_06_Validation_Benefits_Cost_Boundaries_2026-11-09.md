# 深度注意力光譜的驗證體系、效益與成本邊界：等預算實驗、失敗歸因與可證偽研究指標

## 摘要

深度注意力光譜（Deep Attention Spectrum, DAS）提出一個可檢驗的研究問題：人工智慧在不要求使用者反覆改寫相同來源資訊的情況下，能否自主返回原始條件，重新提取、重排與建構任務表徵，並在同域深化、跨域橋接、外部驗證、補充證據及停止之間作出有效的控制決策？本系列第一至第五篇分別建立了問題本體、形式狀態與停止規則、認知控制與混合專家路由分離、DAS-L 學習與梯度接口，以及 DAS-LL 學習事件與神經聯動帳本。然而，這些形式化規約及合成檢查，不能替代對真實模型的公平效能驗證：增加推論輪數、引入外部工具、使用更強的驗證器、挑選有利失敗案例或忽略使用者時間，均可能使研究者錯誤歸因改善的來源。

本文提出 DAS-ARL 的終篇驗證規程。其核心包括：預註冊任務契約與污染邊界；將一次答題、多次同式重試、固定算量搜尋、工具驗證、自我反思、受控表徵重構及 DAS-L 訓練分別設為對照組；嚴格控制模型檢查點、可見資訊、工具權限、推論與訓練成本；在數學、程式除錯、Agent 長程任務及開放性哲學論證中使用**不同的有效性契約**；區分可驗證正確率、原始條件保留、幻覺／無根據斷言、可接受的不確定表達、使用者重述成本、專家路由可觀測性及表徵聯動的因果證據；並將所有額外計算、失敗重試、人工介入、記錄儲存與錯誤行動損失放入全任務成本帳。

本文給出六項具明確假設的條件性命題與反例，提出二十四項尚未量測的驗證指標、階段性實驗規程、停機與反證準則、來源和時間治理要求，以及可重播的**合成**對照資料。其結論並非宣稱 DAS 已降低幻覺或提高 AI 穩定性，而是指出何種證據才可能支持這些主張，何種負結果會使相關主張遭到削弱，以及為何 DAS 不能被簡化為「更多 token、更多專家或更長思維鏈」。本研究系列在此完成理論與實驗規約的第一版；實測效能保留為尚待獨立完成的研究工作。

**關鍵詞**：深度注意力光譜；自主表徵重建；DAS-L；DAS-LL；等預算對照；實驗識別；數學驗證；程式除錯；Agent 可靠性；幻覺；使用者負擔；成本邊界；候選指標。

## 1. 研究定位：最後一篇不應把假說寫成已達成能力

### 1.1 本系列真正需要證明什麼？

第一篇主張「處理完成不等於理解窮盡」，第二篇建立再理解的狀態與可停止性，第三篇把「選擇認知操作」和「選擇底層專家資源」分離，第四篇提出 DAS-L 作為學習控制的候選方法，第五篇說明接觸、檢索、反向傳播、更新、表徵重構和能力保留皆必須不同帳入。這些命題使 DAS 可以被認真研究，卻沒有證明：在現有任何模型上加入 DAS 控制器，必然會更準確、更便宜、更可靠、更有創造性或更像人類理解。

我們不以提出新術語作為研究成功，而以**能否在嚴格公平的比較下，產生無法只由更多運算或更多外部資訊解釋的額外效用**作為核心判準。若某任務已有穩健的一次解法，DAS 理想上應低成本停下，而不是強制反覆重看。若原始問題資訊不足，正確行為可能是標記無法判定並請求補充，而不是藉跨域類比編造唯一答案。若有確定性計算器或程式測試，應允許它作為可靠的外部判準，但不能把工具本身的能力全算成 DAS 內在能力。

### 1.2 要檢驗的四個主張

- **C1：自主再理解**。在未新增使用者語義敘述的任務裡，模型可比同算量對照更常自行找回原始忽略條件，且不增加無根據主張。
- **C2：有效表徵探索**。改善來自可檢查的表徵轉換、原始約束保留或橋接義務，而非單純延長輸出或增加候選數。
- **C3：成本自適應**。簡單任務不被過度處理，困難但可救回的任務得到合理追加資源；納入失敗、工具、人工與延遲後仍可展現可辯護的效益。
- **C4：可學習與可追溯**。經過 DAS-L 訓練的控制器能在未見資料與新的任務域上保留此種策略，並以 DAS-LL 紀錄區分模型內部改變與外部程序幫助。

C1–C3 可在固定模型權重的推論環境測試；C4 涉及學習與泛化，必須比較訓練前後的**未見任務**，不能用同一批訓練題重答作為證據。

## 2. 統一實驗物件：任務、政策、資源、驗證器與時間

### 2.1 任務契約

沿用第二篇，定義任務契約：

$$
\mathcal{T}_i=(x_i,\mathcal{C}_i,\mathcal{E}_i,\mathcal{Q}_i,\mathcal{V}_i,\mathcal{B}_i,\mathcal{P}_i).
$$

$x_i$ 是任務原始資訊與來源快照；$\mathcal{C}_i$ 是原始條件及容許歧義；$\mathcal{E}_i$ 為事先界定的外部證據；$\mathcal{Q}_i$ 為驗證義務；$\mathcal{V}_i$ 是明確版本的驗證契約；$\mathcal{B}_i$ 是資源與時間邊界；$\mathcal{P}_i$ 是工具、安全和行動權限。任何實驗宣稱「同一題」時，除不可避免的隨機性外，不得秘密改變其中任務相關的欄位。

每個實驗單元另記錄模型版本 $\theta_v$、控制政策 $\pi_p$、題目／語義版本 $d_i$、隨機種子 $s_j$、執行日期、可用工具、資料污染級別與成本計量版本。令觀察到的結果為：

$$
Y_{ij}(p,B,V)=U(\theta_v,\pi_p,\mathcal{T}_i,s_j,B,V),
$$

其中 $B$ 是比較時固定或分層的資源上限，$V$ 是獨立驗證契約的版本；函數 $U$ 不必回傳單一數值，它可回傳正確性、條件保存、無根據斷言、完成時間及代價的向量。若結果由外部工具決定，報告必須保留工具能力的可用範圍，不可混同純模型效能。

### 2.2 同一來源與額外證據必須分開

DAS 的中心實驗允許來源 $x_i$ 不變，而表徵狀態、工作記憶、操作或隨機源改變。若模型後來檢索到新材料、執行外部程式、獲得人類提示，則必須另記證據增補事件。它可能有用，但不再是**純同源再理解**的試驗。實驗可設下列模式：

1. `same_source_only`：原文固定、無外部知識注入；容許不同內部操作。
2. `same_source_with_tools`：原文固定、允許明列的決定性工具，但工具輸出另記證據。
3. `augmented_evidence`：允許補入資料與使用者說明；不能與第一類合併比較純自主表徵。

上述三種不是能力高低排行，而是不同的因果識別問題。

### 2.3 驗證結果不是二值萬能答案

採用 `pass`、`fail`、`unknown`、`invalid_contract`、`not_applicable` 等互斥的主要驗證狀態，另記測試覆蓋、證據強度及評審一致性。對規格本身含糊的題目，直接以某個隱藏測試判錯可能不公允；對開放哲學問題，不能使用算術等式的正確率作替代指標。驗證器修訂必須建立新版本，不能以新版本分數改寫過去的判斷。

## 3. 必要對照組：比「再想一次」更嚴格

本文建議至少包含如下可拆分的對照。所有對照必須事先規定其可見資訊、訓練來源、可用工具、最大輸出及延遲限制；不能只給 DAS 額外的語義提示，卻要求基線只執行原文一次。

| 組別 | 簡述 | 目的 | 不可偷偷增加的優勢 |
|---|---|---|---|
| B0 | 一次前向／常規完成 | 觀察首次理解 | 不使用額外人類提示 |
| B1 | 重複輸入、同式重試 | 區分單純反覆與重構 | 不得更換原始問題 |
| B2 | 等候選數 Best-of-N／搜尋 | 控制額外採樣帶來的效益 | 評選器與驗證預算相同 |
| B3 | 固定輪數自我反思／修正 | 控制一般迭代自修 | 不特別提供 DAS 操作標籤 |
| B4 | 同成本外部工具驗證 | 檢查改善是否來自工具 | 工具功能與配額透明 |
| B5 | DAS 控制器、關閉跨域操作 | 衡量同域再理解 | 其餘能力及路由保持一致 |
| B6 | DAS 控制器、開啟跨域但不聯動 MoE | 衡量跨域控制本身 | 不增加額外專家參數 |
| B7 | DAS 雙層認知／專家路由 | 衡量路由聯動的附加值 | 可觀測的專家模型與權重相同 |
| B8 | 經 DAS-L 訓練的控制器 | 檢查可學習性與保留 | 與對照共享訓練資料和成本帳 |

B7 僅適用能控制底層專家路由的系統；黑箱 API 無法獲得內部路由時，應標記 `not_applicable`，而非模擬專家數據。實作可分階段選擇子集，不要求一次建立全部組別；但任何主要因果聲稱都要有一組能排除相應替代解釋的對照。

## 4. 等成本的定義不能只選擇有利單位

### 4.1 多維成本帳

任務的總成本建議保留為向量：

$$
\mathbf{K}_i=(k_{\mathrm{tokens}},k_{\mathrm{FLOPs}},k_{\mathrm{latency}},k_{\mathrm{tool}},k_{\mathrm{human}},k_{\mathrm{retry}},k_{\mathrm{risk}},k_{\mathrm{storage}}).
$$

必要時另列能源、機會成本、訓練攤提、環境外部性與硬體折舊，但不可把同一 GPU／電力費用既計入 API 租金又重複折舊。`human` 包含使用者重述、工程人員修正、專家評審及授權審批；`risk` 包括錯誤部署、不可逆行動和資訊洩漏的可估計損失，若無法可靠量化則列為獨立風險類別，不任意填零。

### 4.2 比較規則

主比較以**相同模型、相同權限、相同來源條件及固定算量窗口**為優先。可以分別報告 token-matched、FLOP-matched、wall-clock-matched、money-matched 和 end-to-end-matched，因為這些約束不一定互相等價。若兩組部署架構完全不同，需對照硬體、併行、快取、batch、工具延遲與收費單位，避免簡單拿 token 數代替實際成本。

對能夠早停的策略，固定的是**每題最大可用預算**，不一定要強迫所有策略消耗滿額度；額外報告平均消耗與達到成功的總成本。若把未用完的預算視為失敗，反而會懲罰高效率停止。

### 4.3 成功案例的成本不能代表總成本

定義任務集合 $\mathcal{I}$，成功變數 $z_i\in\{0,1\}$，總成本 $K_i\geq 0$，則：

$$
\mathrm{CostPerVerifiedSuccess}=\frac{\sum_{i\in\mathcal I}K_i}{\sum_{i\in\mathcal I}z_i},\qquad \sum_{i\in\mathcal I}z_i>0.
$$

若分母為零，標記 `undefined_no_success`，不可填 0。此處使用的 $K_i$ 必須說明是何種貨幣或資源單位；多維成本在沒有明確匯率／效用函數時，不能直接任意加總。平均成功案例成本可以另報，但絕不能代替「所有嘗試成本除以成功數」。

## 5. 數學驗證：計算正確、命題成立與方法品質三者分離

### 5.1 三種不同的評分契約

對**有限且具確定答案**的運算題，可以使用整數／有理數精確比較、符號化簡、決定性程式檢查或可核查的步驟憑證。對**形式證明**，必須分辨語法合法、型別檢查通過、命題前提被忠實輸入、定理確實獲證，以及形式系統本身的可靠性前提；不能把成功生成一串看似證明的文字當成已完成證明。對**開放研究猜想**，驗算大量特殊案例僅能累積支持或尋找反例，不可由有限驗算推出無限全稱命題。

第四篇提到的 felra／SREG／確定性計算接口可以作為候選實驗組件，但本稿不假定其獨立檢查器已覆蓋所有數學領域。若使用外部證明器、Python／SymPy 或其他程式，必須固定版本、輸入序列、輸出雜湊及執行憑證；所有程式例題的測試通過都只能支持測試涵蓋範圍內的主張。

### 5.2 把「初次失敗」建立成預先定義的任務子集

令 $Z_i^{(0)}$ 表示在**隨機分配前**，由固定 B0 規程得到的任務初始通過狀態。可定義：

$$
R_p=\Pr\bigl(Z_i^{(p)}=1\mid Z_i^{(0)}=0\bigr).
$$

這個量估計「對已被固定初始測試認定失敗之任務的救回率」，並不等於所有任務的最終正確率。若對每個處理組各自依處理後結果挑選「最初錯誤」子集，將產生選擇偏誤。研究者應使用公共前測或預先註冊的初始狀態標籤，並公布這部分樣本量及基線選擇方式。

### 5.3 錯誤分類

至少分離：計算錯誤、量詞／條件遺漏、類型或維度錯誤、不正當的全稱化、從類比跳成證明、驗證器誤判、正確表示但錯誤執行、資料／題目缺失、合格的拒答／未知。DAS 若降低某種錯誤卻增加另一種，不能僅用總分掩蓋。所有拒答、超時、資源耗盡及工具失敗均應依預先定義的終態計入分母。

## 6. 程式除錯：必須衡量最終行為而非補丁的說服力

程式題應保留原始 issue、程式庫版本、環境、測試契約和允許檔案範圍；將新補丁置於乾淨且可重建的執行環境。最終結果至少包括：修正指定 bug、未破壞既有行為、無額外安全風險、變更範圍合理、無隱藏資料外洩，以及能否在其他種子／環境重現。不可只以「寫出了補丁」或「自己說已修好」計算完成。

SWE-bench 系列曾提供真實 GitHub issue 的基礎，SWE-bench Verified 亦以人工審核改善題目品質；但 OpenAI 於 2026-02-23 公開指出其存在測試問題與訓練污染，已不再推薦將其當成最前沿程式能力的主要衡量方式 [8]。因此，本文的測試設計應優先使用訓練截止日以後的私有、輪替或重新建構的程式任務，並可參考 LiveCodeBench 對時間切割與自我修復任務的做法 [9]。這不代表任何標榜新題的資料集自動完全無污染；仍需保存可得時間與洩漏稽核。

需分別記錄：(a) 每題提出候選補丁數；(b) 自動執行／檢查次數；(c) 通過單元與迴歸測試的比例；(d) 對未見測試的泛化；(e) 路徑回退和過度修補；(f) 用戶／工程師實際介入次數。若 DAS 提高補丁通過率只是因多執行一倍測試或引用含答案資料，該結果不能支持 DAS 特有的表徵重建效應。

## 7. Agent 穩定性：任務完成與制度約束分開計算

Agent 的控制環境比單次問答複雜：它含工具權限、狀態機、可能改變的外部環境、不可逆操作及多輪使用者互動。對每題記錄目標狀態、允許行動、禁止行動、工具與使用者回合、出錯後的可恢復性和最終狀態。除成功率外，也要研究**跨重跑一致性**、超權限行動、錯誤持久化、狀態漂移與可逆性。

$\tau$-bench 以工具—Agent—使用者互動及最終資料庫狀態檢查提出跨多次試驗的一致性指標 [10]。沿用其研究動機，定義一個任務在相同條件下重跑 $k$ 次都通過的頻率：

$$
\widehat{\mathrm{pass}}^{\,k}=\frac{1}{N}\sum_{i=1}^{N}\prod_{j=1}^{k}z_{ij}.
$$

這是指定有限樣本與重跑規程下的估計量；不把它直接當成獨立同分布條件下的理論機率，也不必然等於單次成功率的 $k$ 次方。環境重置、工具速率限制、外部狀態、隨機源與資料可得時間都可能產生相關性。對不可逆外部動作，研究原則是先在隔離的模擬環境，利用安全守門與授權機制，再討論實際部署，不用危險行為來證明認知深度。

## 8. 哲學與開放性理論：高階表徵不能以答案唯一性衡量

同一段哲學文字在重新閱讀後，可能產生新的前提分解、語義可能性、反例、跨學科映射或形式條件。這些有研究價值，但其評估不能套用算術精確解的同一尺度。建議採取多個可檢查維度：

1. **忠於原文**：候選詮釋沒有捏造原文沒有的前提或作者立場。
2. **論證有效性**：若主張具有演繹形式，前提到結論的推導可接受形式或專家檢查。
3. **異議識別**：是否發現能真正反駁或限定初次詮釋的對立解釋。
4. **映射義務**：跨域類比有明確的對應項、保留結構與失敗條件。
5. **知識邊界**：當資料不足時，能否明確標示多解、不可判定或需要補證。
6. **評審可靠性**：獨立盲評者的一致性及分歧類型分別呈現。

可以研究新解釋是否更具啟發性，但不能把主觀「深刻感」直接等同真理。對跨領域模型，應由受過相應專業訓練的評審或受控的反例任務檢查，而不能要求單一 LLM 評分器自評自證。學術性的多義性不是待消除的所有錯誤；當原文本身有意包含多解時，能**保留多種可辯護表徵**本身可能比過早收斂到一個答案更好。

## 9. 表徵變化：需要機制證據，卻不能過度解讀神經元

DAS 的獨特聲稱涉及重新提取與重組，因此單看最終回答不足。可同時保存：來源約束快照、抽取的條件集合、候選表徵節點、候選之間的轉換邊、驗證義務、控制操作、專家或工具路由的可觀測證據，以及最終結果。對開放權重系統，還可測不同層／模組的活化或表示相似度；對封閉模型，沒有內部遙測就不得推算神經元路徑。

然而，**表示距離不等於有效新理解**。若對表示施加不影響任務行為的可逆基底變換，其向量座標可大幅改變，但語義與輸出不變。反之，即使輸出相似，也可能由不同路由與隱狀態產生。CKA 等表示相似度工具可提供有限的可比較結構資訊，並非理解深度或知識因果的單一真理指標 [11]。如欲聲稱特定模組對改善具有因果作用，需要事先設計控制、消融或局部干預，並評估干預的副作用。

## 10. DAS-L 訓練效益：模型學會策略，不能只學會題庫

### 10.1 固定訓練資訊與算量

比較 DAS-L 與非 DAS-L 時，需匹配訓練樣本可得範圍、總 token／FLOPs、初始檢查點、優化器、學習率排程、參數規模、訓練資料的重複暴露及允許的教師模型。若 DAS-L 使用額外生成的解題歷程，必須將其生成與驗證成本計入，並把該訓練資料與對照共享或進行明確的增量資料消融。

### 10.2 觀測三個互不等價的結果

- **訓練域內改善**：受訓問題上的修正能力，可能僅代表記住題型。
- **未見域遷移**：未見題型或任務域中的再理解策略提升，才對一般性主張有說服力。
- **延遲保留與遺忘**：經新一輪學習後是否仍能重現舊能力，須固定檢查點與測試時間。

第五篇 DAS-LL 可追蹤接觸、前向、反向、優化器更新、來源—模組關係；但即便帳本十分完整，也不能只憑事件數推定某個知識已經「寫在神經網路裡」。若要作因果歸因，應比較保留／移除訓練訊號、資料替換或控制器干預，並審查其可辨識前提。

### 10.3 梯度結果不直接證明理解

第四篇的固定步數循環鏈式梯度、截斷反向傳播與策略梯度都能成為可實作候選，但數學上「梯度可算」僅代表某個目標可在選定條件下優化。模型可以學會延長推理、誤導驗證器或追逐代理獎勵。故 DAS-L 的學習效益必須另外通過獨立保留測試、反獎勵駭入測試及新問題泛化，而非以 loss 下降作唯一證據。自我修正研究對公平比較與可靠外部回饋的重視，也支持這項保守做法 [2][3]。

## 11. 避免把實驗對象與外部驗證器混成同一系統

任何外部驗證器均有**作用範圍**與**錯誤模型**。對精確整數加法，可以建立相對強的決定性對照；對大型程式、實務事實或開放哲學題，測試集和評審通常只覆蓋部分義務。驗證器即使是獨立模型，也可能共享訓練污染、偏見或錯誤推導路徑。

因此至少保存四個欄位：`verifier_identity`、`verifier_version`、`covered_obligations`、`uncertainty_or_disagreement`。對不同版本驗證器產生的分數，不作不經調整的時間序列合併。若使用 AI 作評審，應公布提示模板、題目順序隨機化、評審盲化、評審間一致性，以及與可驗證子集的校準。

**反獎勵駭入**檢查亦不可省：例如故意提供一種容易討好文字評審，卻違反原始條件的「深刻解釋」，看控制器是否會選擇它；或構造能通過公開單元測試但破壞未見條件的程式補丁。DAS 若在外評中更容易接受此類錯誤，即使內部自評更高，也應視為負結果。

## 12. 污染、時間與比較公平性：歷史資訊不可倒流

嚴格評估至少保存三個不同日期：`task_first_available_at`、`model_training_cutoff`（若未知則標 `unknown`）和 `evaluation_run_at`。對外部工具另列 `retrieval_snapshot_at`。題目由先前公開文件衍生、測試洩漏、模型自帶的程式庫知識、公開排行榜反覆優化，都會影響成績解讀。

靜態題集不必然毫無價值，但應區分：`public_historical`、`private_holdout`、`newly_generated`、`temporal_holdout`、`known_contaminated`、`unknown_exposure`。任何標成 `unknown_exposure` 的題組，不能直接宣稱「已排除污染」。可參考 LiveBench 定期更新與客觀答案的原則 [12]，亦需處理題目被持續公開與測試環境改版的問題。

預註冊也須約束研究者自由度：不得在看見測試分數後改變成功分母、挑選最有利的提示方式、忽略不利模型、改寫驗證器、刪掉超時樣本或只回報漂亮的圖例。對可調整的深度預算，應在獨立開發集調參，在測試集僅執行一次固定評估規程，必要時以版本化評估紀錄保存後續更正。

## 13. 六項條件性命題、證明與反例

### 13.1 DAS-F06-P1：只有效能增益，不能識別特有表徵機制

**命題**：若只觀察最終輸出與任務成本，且至少存在兩個內部機制不同、卻產生相同觀察分布的系統，則觀察資料不足以唯一識別增益由 DAS 表徵重建所致。

**證明**：構造系統 A 使用表徵重構與驗證；系統 B 使用固定候選搜尋與相同的選擇器。若在研究任務集合上兩者的輸出、成本及外部事件具有相同分布，則任何只以上述觀察為輸入的辨識函數，都無法在所有情況正確區分 A 與 B。要識別內部機制，必須引入對關鍵控制器或表徵操作的介入、內部遙測或具有鑑別力的新任務。證畢。

這不證明 DAS 沒有效果，而是要求我們不要用一項任務正確率直接宣告機制已被發現。

### 13.2 DAS-F06-P2：固定契約的最佳已驗證封存分數可單調不降

**命題**：在同一固定驗證契約下，若所有已驗證候選均被完整保留，且其評分不會被改寫，則「截至第 $t$ 步已驗證候選的歷史最高分」單調不降。

令 $A_t$ 為截至第 $t$ 步的候選集合，$A_t\subseteq A_{t+1}$，且 $v(r)$ 是固定可比較分數，定義：

$$
M_t=\max_{r\in A_t}v(r),\qquad M_{t+1}\geq M_t.
$$

**證明**：集合包含關係確保前一時刻最高分候選仍是下一時刻的可選候選，因此取最大值後不會減小。證畢。

**邊界**：這只說明記錄系統中「歷來最佳且已驗證候選」的數學性質；若對外選錯候選、驗證器失準、契約改變或只保存部分答案，實際部署結果仍可能退化。第二篇的相應命題不能被擴張成所有 DAS 推理步驟必然改善。

### 13.3 DAS-F06-P3：有限可用預算並不自動保證最佳效益

**命題**：若每個繼續探索操作消耗至少 $\varepsilon>0$ 的可記帳預算，且初始可用預算有限為 $B<\infty$，則任何不超支的探索序列操作數 $N$ 滿足：

$$
N\leq\left\lfloor\frac{B}{\varepsilon}\right\rfloor.
$$

**證明**：$N$ 次操作最低成本為 $N\varepsilon$，在不超過 $B$ 的條件下即得上界。證畢。

**反例**：一個控制器即使僅做五次探索，也可以每一步選錯方向，最後完全沒有有效候選。終止性是**資源性質**，不是正確性、智慧或最佳停止的證明。若有零成本無限操作、未計入的外部工具或隱含重試，此上界失效。

### 13.4 DAS-F06-P4：只看成功案例成本可能顛倒整體成本結論

**命題**：在存在失敗成本時，依成功案例條件平均成本排序，不必與全部嘗試成本／成功數的排序一致。

**構造反例**：合成策略 A 嘗試十題，其中一題成功花費 1 單位，九題失敗各耗 100 單位；策略 B 嘗試十題，其中八題成功、兩題失敗，每題皆花費 5 單位。則 A 的成功案例平均成本為 1，B 為 5，若只看成功案例會認為 A 更便宜；但總成本／成功數分別為 $901$ 與 $50/8=6.25$。此反例使用同一種抽象成本單位，數值純屬合成，證明兩種排序不等價。證畢。

因此「DAS 一次成功時 token 很少」不能推出部署的總成本較低，必須包含失敗與重試。

### 13.5 DAS-F06-P5：不完整的內部可觀測性不能推定未觀測事件為零

**命題**：若帳本只觀測到某事件類型 $n$ 次，且未提供對漏記數量的有限上界，則真實發生次數只能確定至少為 $n$，不能由帳本推出有限的精確總數。

**證明**：對任何整數 $m\geq n$，均可構造同一份可見紀錄，但另含 $m-n$ 個不可觀測事件的實際歷程；除非增加記錄完備性或上界假設，資料無法排除其中任何一種。證畢。

因此 MoE 黑箱專家調用、內部前向次數、未公開權重更新等項目，應填 `unknown` 或 `not_measured`，而非零。第五篇 DAS-LL 的事件數是可觀測事件計數，不自動是所有實際事件總數。

### 13.6 DAS-F06-P6：不可靠評審可以將實際排名反轉

**命題**：在缺乏與目標有效性一致的評審假設時，兩系統依評審分數的排序不必等於依真實任務契約的排序。

**構造反例**：設系統 A 對十題有八題真正符合契約，但某不良評審僅判其中兩題通過；系統 B 僅有六題符合契約，卻因過度迎合評審表面規則而被判九題通過。依該評審排序 B 優於 A，依真實契約則反之。兩套計數可以同時成立，故單靠有偏的評審排名不能識別真實優劣。證畢。

這不是任何現有評測器的實測指控，而是說明獨立驗證、錯誤稽核與不確定標記必須保留。

## 14. 統計規程：先定義比較單位，再談顯著性

### 14.1 配對比較與多重重跑

對任務 $i$ 的策略 $p$ 與基線 $b$，若有共同測試條件及事先定義的結果量 $Y$，設定：

$$
\widehat{\Delta}_{p,b}=\frac{1}{N}\sum_{i=1}^{N}(Y_{i,p}-Y_{i,b}).
$$

但這個式子只適合可有意義相減的同尺度結果。若任務成功是二元而有多種重跑種子，應報告每題分層均值、任務群組的聚合及相依性；同一題的多次重跑不應當成完全獨立的新題目。可以使用依題目或來源專案分群的 bootstrap／隨機化檢定，並報告信賴區間、效果量和分群規程，不只回報單一 $p$ 值。

### 14.2 分層、分母與缺失

預先決定題目難度、領域、可驗證性、原敘述充分性、模型大小、污染級別、是否使用外部工具、可觀測性、任務延遲上限等分層。尤其「對原文已充分、首次誤解的題目」應與「原文本身缺資訊」分開；否則研究者可能把 AI 對後者的合理詢問誤算成能力退化。

未完成、超時、缺遙測、無權調用、驗證失敗與驗證未知分別呈現，不要把所有缺失都塞進分母後當零；對主要結果則事先規定保守處理規則，例如超時視未完成，但另報工具故障造成的缺失比例。

### 14.3 多重比較與停止研究規程

若同時檢測二十四個指標及數個任務組，偶然顯著結果的機率自然提高。可先指定少數共同主要結果，例如「相同總預算下的外部驗證成功率」、「無根據斷言率」、「全任務成本／成功數」、「使用者重述次數」，其餘為探索性結果；若報告大量假說檢定，應事先選擇多重比較調整方式。

研究停止分兩層：一是模型執行層的每題早停，二是實驗研究層的資料蒐集停止。後者不可因看見某個顯著結果就無註記提前結束；若採序貫設計，應事先定義花費函數、監測頻率及有效的區間或檢定方法。

## 15. 自主觸發、停止與人類重述負擔

把使用者重述次數 $H_i$ 定義成**任務規程中為了補救理解錯誤而額外提供的語義性重新敘述次數**。把必要補充事實、權限批准、合法澄清及使用者更改目標另記，不能都當成「AI 不懂所以害人重述」。有時 AI 詢問澄清是負責任的行為，而不是負面表現。

研究應把觸發設計分成：(1) 明顯矛盾；(2) 初次驗證失敗；(3) 高風險外部操作前；(4) 估計新表徵可能帶來效益；(5) 人類已暗示重新查看；(6) 無足夠證據。對各觸發類型分別量測過度探索、錯誤停止、無效跨域連結與不必要人類干預。DAS 可能在某些數學或程式案例減少重述，在事實不充分或道德／哲學問題中卻增加必需的澄清：兩者並不矛盾。

## 16. 能力、使用性與可靠性：不可合併成虛構的單分數

若 A 的數學正確率上升，但延遲翻倍、使用者成本下降、Agent 無權限動作增加，不能簡單說 A「總分更高」。本文建議保留**主要結果向量**：

$$
\mathbf{O}=(S,Q,F,A,R,K,H,C),
$$

其中 $S$ 為指定任務成功、$Q$ 為來源條件忠實／驗證品質、$F$ 為無根據斷言或無效候選、$A$ 為恰當承認未知、$R$ 為多次重跑穩定性、$K$ 為成本向量、$H$ 為人類重述負擔、$C$ 為紀錄與比較可觀測性。這些符號**不是**跨所有任務都具有相同的尺度；報告必須展開其操作定義。應先報各軸的效果和 trade-off，再允許具明確偏好與風險政策的應用方設定效用函數。

把 DAS 描述為 AI「懂了」的完整證明會超出可操作化的範圍。可以證明某些任務上回復原始條件、提高外驗成功或減少人類修正，但無法由此推定模型的所有可能理解皆已被搜盡，更不能證明主觀理解或人格地位。

| DAS-V05 | 同域深化有效率 | 有效同域操作／可驗同域操作 | 域分類標未知項 |

| DAS-V09 | 無根據事實斷言率 | 缺必要證據而確定宣稱之項／可稽核事實宣稱 | 非所有無法查核即判錯 |
| DAS-V10 | 不確定表達適切率 | 在不可判定題上合理標記未知之件數／有標註題 | 拒答不等於正確完成 |
| DAS-V11 | 程式隱藏測試通過率 | 通過未見測試之補丁／全部合格提交 | 測試集污染需追查 |
| DAS-V12 | 程式回歸破壞率 | 新破壞已保證行為之補丁／合格補丁 | 環境版本一致 |
| DAS-V13 | Agent 終態達標率 | 合規到達目標狀態之試驗／全部試驗 | 非僅最後文字答覆 |
| DAS-V14 | Agent 多跑一致性 | $\widehat{\mathrm{pass}}^{\,k}$ 與各 $k$ 的對照 | 重跑未必獨立 |
| DAS-V15 | 越權或不可逆錯誤率 | 有明確違規或不可逆錯誤之試驗／合格試驗 | 需模擬安全邊界 |
| DAS-V16 | 人類語義重述負擔 | 為補救初次誤解所需額外重述／任務 | 澄清與補證另帳 |
| DAS-V17 | 完整任務總成本 | 所有成功、失敗、重試與人類成本向量 | 禁止只算成功案例 |
| DAS-V18 | 每有效成功總成本 | 全部嘗試成本／外驗成功數 | 零成功記未定義 |
| DAS-V19 | 延遲尾部成本 | p50、p95、p99 任務時延及超時比例 | 固定硬體和排隊策略 |
| DAS-V20 | 無效探索率 | 無通過新義務且消耗預算的操作／探索操作 | 未驗證與無效分開 |
| DAS-V21 | 早停適切性 | 符合預註冊停機契約之決策／可判定決策 | 反事實最佳值通常未知 |
| DAS-V22 | 等預算路由消融效果 | 全模組與移除指定認知／專家路由的配對差 | 參數與控制介入對齊 |
| DAS-V23 | 未見題策略保留效益 | DAS-L 相對對照在保留集與延遲測試的效果 | 訓練暴露與檢查點固定 |
| DAS-V24 | 數據污染與可觀測性覆蓋 | 已審核任務／事件占應審核範圍之比例 | 不可將未知寫成零污染 |

這些指標與其資料字典的候選版本，可由機器可讀 `data/das_f06_indicator_catalog.json` 查閱；全系列整合索引可由 `data/das_arl_indicator_catalog_v0.1.json` 提供。**數值欄位統一為 `null`，狀態為 `not_measured`**，直到收到具來源時間、執行環境及驗證者版本的真實觀測。特別是只有條件性形式命題和合成 fixture 的本系列，不能被系統判定為「已通過真實 AI 實驗」。

## 18. 分階段實驗規程：把成本壓在適合的地方

### 18.1 階段 A：固定且微型的可重算題型

使用確定性算術、整數約束、不變量與具有限反例的題集。先建立資料分割、原始來源雜湊、標準答案或可重算驗證器、三個常規推論基線。DAS 可暫由外部控制器實現，不要求修改 Transformer。所有資料使用 `synthetic` 或另有真實來源憑證的類別，避免把演算法測試樣本混成模型訓練結果。

### 18.2 階段 B：固定權重下的表徵重構消融

對同一模型與工具限制，依次比較 B0–B6；保留每次操作、候選表示、來源條件回訪與驗證憑證。先確認 DAS 是否在等預算下有改進，再檢查去掉同域重構、跨域橋接或外部驗證時是否失去效果。若只在加大 token 預算時改善，而同成本沒有進展，便不能聲稱 DAS 特有增益。

### 18.3 階段 C：程式與 Agent 隔離環境

以固定容器執行程式題、以可還原狀態機或模擬 sandbox 執行 Agent 題。評估最終狀態、隱藏測試、回歸、權限、超時及多次重跑穩定性。逐步加入不可逆風險的代理指標，但研究不得繞開授權或真實部署的安全控制。

### 18.4 階段 D：小型可訓練控制器

在相同基座與訓練成本下，對照控制器監督訓練、策略梯度、固定循環深度與 DAS-L。可使用小規模數學特化模型作初始實驗；若模型規模不足以顯示某個效果，應報告陰性結果與估計不確定性，而不是只用更大模型掩蓋。在能力驗證前，不得把梯度流程能運行當成技術有效的證據。

### 18.5 階段 E：跨域泛化與真實成本

將已確立的對照條件移至未見的數學、程式、哲學論證及 Agent 任務域，量測延遲、總成本、人類重述、錯誤密度和模型保留性。僅在同成本或已報告成本—效益權衡成立時，才可支持 DAS 對實際部署有淨收益。不同領域不保證均有增益：研究應允許結果呈現為任務條件依賴。

## 19. 預註冊契約與報告模板

每個可引用的 DAS 效能報告，至少應包含：

| 類型 | 必填內容 |
|---|---|
| 研究身份 | `study_id`、日期、作者、版本、預註冊連結或雜湊 |
| 基座 | 模型檢查點、權重是否變更、架構、量化與設定 |
| 任務 | 題目來源、首次可得時間、原文雜湊、任務契約 |
| 比較 | 策略版本、基線選擇、隨機分配與種子、匹配成本維度 |
| 證據 | 工具與檢索快照、資料洩漏稽核、權限、驗證契約與獨立性 |
| 成本 | token、FLOPs、延遲、工具、人類介入、失敗成本與測量缺失 |
| 結果 | 成功、未知、拒答、超時、錯誤種類、分群效果量與區間 |
| 表徵 | 來源約束回訪、候選轉換憑證、同域／跨域分類與其不確定性 |
| 路由 | 若可觀測，列認知控制及 MoE 專家路由；否則列未知 |
| 治理 | 隱私與授權條件、資料保存政策、可公開／不可公開證據 |
| 負結果 | 未改善的任務、失敗案例、已知偏差與停止規程 |
| 發表 | `synthetic`、`pre_registered`、`observed`、`independently_replicated` 等明確證據狀態 |

研究者可以提供程式碼與匿名化聚合結果，但不必為了可重算而公開個人對話、受保護文件、私人 GitHub 原始碼或機密模型權重。某些證據受權限約束時，應明列哪些主張只能由授權審計者核查。

## 20. 可證偽性：哪些結果會削弱 DAS？

1. **零額外增益**：在配對樣本與等成本條件下，DAS 無法勝過 Best-of-N、受控自修或外部工具對照，且差異區間排除預註冊的最小實用增益。
2. **驗證錯覺**：內部自評上升，外部或隱藏測試卻沒有改善，甚至出現更多無效跨域橋接。
3. **無成本優勢**：小幅成功率提高，但把失敗、人類、延遲與工具成本計入後不具可接受的部署效益。
4. **不具有自主性**：有效改進必須依賴人類反覆提示「再看這裡」，沒有降低原本的重述負擔。
5. **無法遷移**：控制器只對訓練題型有效，新的任務領域與保留測試沒有穩定效果。
6. **無機制識別**：拆除假定的表徵控制操作不影響結果，且效益完全由外部驗證器、額外採樣或路由容量解釋。
7. **傷害原有能力**：對簡單題過度思考、增加幻覺、遺失原始條件，或在 Agent 中提高越權、不可逆錯誤與失敗率。
8. **無法記錄與審核**：關鍵事件、驗證者版本或路由證據不可觀測，卻持續把未知當作已證實的學習過程。

上述結果可能否定特定實作或某些廣泛宣稱，不必然否定「同源再理解值得獨立研究」這個問題本身。反之，若出現正結果，也只支持測試契約和條件範圍內的推論，不應升格為 AI 一般智能、主體性或所有領域理解已完成的證明。

## 21. 合成測試與正式資料的分界

本系列附有一份**顯式標記為 `synthetic`** 的微型多政策試驗 fixture，以及 `validation/das_f06_sanity.py`。它的用途不是測量任何真實模型，而是檢查資料型別、分母計算、等預算旗標、未量測值表示、跨重跑一致性、錯誤樣本計入與成本口徑是否依規約實作。

該測試特別防止三類常見誤解：一是僅保留成功案例而把失敗成本丟掉；二是把同題兩次重跑視為兩個獨立題目；三是把合成對照中的 DAS 標籤當作已發現真實的效能提升。即使全部測試都通過，也只能說**計量程式在有限例子中與指定定義一致**，不能說 DAS 的實際演算法有了新的能力。

正式實驗要另建立 `real_observation` 證據類別，必須提供模型版本、真實輸出憑證、來源時間、驗證環境與原始計數；若只有他人論文的測量數據，應標為 `external_reported`，不得偽裝為本實驗室的自主實測。

## 22. 導入 Frontier-Scaling-Lab 的資料治理與相容性

此次系列的總共七十二項候選指標，按功能分為第三篇的十二項認知／專家路由（DAS-R）、第四篇的十六項學習控制（DAS-L）、第五篇的二十項事件與神經聯動（DAS-LL），以及本篇的二十四項效益／成本驗證（DAS-V）。指標總數代表**分類粒度，不代表模型能力分數或研究成果數**。

建議在 Frontier-Scaling-Lab 中以追加式、獨立的 DAS 研究軌道保存：原始六篇 UTF-8 Markdown；未量測指標目錄；schema 與合成重播；定義／來源索引；檔案雜湊及版本。不得改寫該倉庫既有 SAS、前沿擴張、地緣、法律或製造能力指標。後續若更新某一項定義，應使用新版本與可追蹤的 supersession 關係，不默默覆蓋舊定義。

所有候選指標的 `value=null`、`observation_state=not_measured` 與 `evidence_class=definitions_only` 是規範的一部分，不是尚未填值的疏漏。只有完成真正的資料採集與驗證，才可能另追加觀測事件；不可因本篇提供數學命題、合成測試或文獻引用，就將觀測狀態升格為 `observed`。

## 23. 學術比較與概念新穎性的適當邊界

Universal Transformer 的迭代運算與自適應深度、Self-Refine 的自回饋、自我修正的強化學習、test-time compute 配置、動態 MoE 路由與訓練資料影響追蹤，均與 DAS 的某些子元件重疊 [1]–[6][13]。因此，不能僅以「重複看同一句話」宣稱發明了前所未有的注意力數學原理。

DAS-ARL 值得提出的可驗證組合是：**把來源同一而工作表徵可變的自主再理解、同域／跨域操作分歧、雙層認知與資源路由、學會再理解的訓練機制、事件／神經證據分級，以及包含人類重述成本的效用測量，放進同一個可被反駁的研究契約。** 其中每個組件是否在工程上產生獨立且可泛化的新增效益，仍要透過本篇規定的比較證明。

研究者也應避免因類似既有方法而否認問題的研究價值：組合式研究可以有貢獻，但必須指出額外可檢驗的假說、接口與效果，而不是依靠命名或敘事取得優先權。

## 24. 六篇系列整體結論

本系列從使用者常見的挫折出發：一段原本已經包含必要條件的話，為什麼 AI 看過後仍反覆沿用第一次的表徵，必須等使用者再次提示，才可能重新理解？它提出，人工智慧的認知系統可以研究如何在資訊來源不變時主動重建表徵，但這種探索必須具備有效性、成本與停止的界線；同域深化和跨域連結不是同一操作；MoE 專家選擇不是認知探索本身；推論時的重新理解也不等於訓練時的參數學習。要研究 AI 「學過某份資料幾次」，還須分開接觸、檢索、前向、反向、更新、再次使用與可確認的能力保留。

因此，本文最後把 DAS 從單純的構想轉成一套尚待實測的**可操作研究綱領**：有基線、有失敗類型、有計量單位、有資料治理、有條件性證明、有可重播的合成測試，更有允許否定自身假說的標準。這不保證新架構一定成功，但使後續研究者不必把「AI 想得久一點」當作理解深度的唯一替代物。

> 深度注意力真正值得追問的，不是模型把一段資訊看過多少次，而是它是否知道自己曾經忽略了什麼、如何有根據地重新建構，以及何時應當停止把新的解釋誤當新的真理。
