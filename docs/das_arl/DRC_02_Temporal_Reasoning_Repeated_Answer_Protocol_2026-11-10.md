# 深度表徵猜想 II：同題多時間、多輪推理與完成態回答的實驗規約

## 摘要

本稿將深度表徵猜想（DRC）轉換成可重現的第一階段實驗：**固定同一個問題、同一模型版本及受控條件，改變推理時間／預算、第一次至第 X 次的推理輪次，以及每次推理完成後的結果是否回填到後續上下文**，觀察回答及語義結構的變化。原始構想包含「不使用額外推理直接回答」、思考約 30 秒、40 秒、50 秒、60 秒及更長的完成態回答，並比較第一次、第二次乃至第 X 次的回答差異。

本稿尤其區分：獨立重新起跑、只在執行順序上重複、對模型提供前次答案、將前次結果對使用者隱藏但提供模型，以及真正延續內部隱狀態。這些在工程上是不同處理，不能混稱「AI 第二次思考」。第一層觀測只能證明**外部答案或其可評估結構不同**，不能僅憑不同答案就斷言模型內部出現高維場的特定測地線軌跡。

**實驗狀態**：以下所有數值為待預註冊的設計值，未執行真實模型試驗，沒有實測效能或 DRC 的支持性結果。

## 1. 研究問題與需分離的因素

DRC 第一次實驗的主要問題：

1. 同一模型對同一問題，不增加推理與增加推理是否產生不同結果？
2. 30／40／50／60 秒等不同推理時間預算是否改變回答、正確性與解釋結構？
3. 在相同總預算下，**一次長推理**與**多次較短推理**是否有不同結果？
4. 第 X 次結果變化是重複隨機抽樣、前次答案的上下文效應，還是實際可續存的隱狀態效應？
5. 新增解釋是否得到原始題目或外部證據支持，抑或出現幻覺、過度詮釋或過度思考？

上述問題需要對照組，不可把時間和思考次數合併成一個模糊的「深度」指標。

## 2. 固定任務與實驗單位

每個任務使用一份不可變問題 $X_i$，附上來源版本、語言、任務領域、難度與獨立驗證規約 $V_i$。主要實驗單位是：

$$
R_{i,m,b,k,c,s},
$$

其中 $i$ 為題目，$m$ 為模型快照，$b$ 為推理預算組，$k$ 為第幾次推理，$c$ 為歷史／上下文處理方式，$s$ 為隨機種子或受控重複識別。若服務不支持設定 seed，記 null，不得臆造可控種子。

至少保持一致：模型及 tokenizer 版本、系統指令、工具可用性、溫度／取樣策略、輸入原文、輸出格式、解碼模式、適用的隱藏推理設定、評分器版本。不可將產品版本升級前後的回答混成同一組。

### 2.1 題目類型建議

- **有限數學**：可由獨立算術或程式 oracle 驗證計算與命題。
- **程式理解／除錯**：有固定原始碼、可重現測試及隱藏回歸題。
- **中文哲學文本**：有完整段落及原文，可評來源忠實度、概念抽取及過度超譯。
- **跨域理論比較**：事先界定可用來源、可接受的類比與需要額外外部證據的界線。
- **Agent 沙盒（後期）**：要求任務與權限固定，先不執行真實外部副作用。

語義題與哲學題的評分不能強制使用單一正確答案；須評原文支持、推理合法性、替代解釋與證據範圍。

## 3. 時間預算與推理預算：不得假裝完全相等

建議的第一批時間組：

| 組別 | 意圖 | 記錄 |
|---|---|---|
| T0 | 直接回答，不要求額外思維鏈 | 實際計算耗時與 Token，不能宣稱零內部推理 |
| T30 | 目標推理時間上限約 30 秒 | 實際時間、是否完整完成、推理量（若可測） |
| T40 | 目標約 40 秒 | 同上 |
| T50 | 目標約 50 秒 | 同上 |
| T60 | 目標約 60 秒 | 同上 |
| T90／T120 | 可選更長預算 | 同上；若不可控則只作探索組 |

**關鍵工程限制**：一般 API 可能只能設定推理 effort、Token 上限、服務超時，而不能要求模型恰好「完整思考 40 秒」。牆鐘秒數也包含排隊、前綴處理與網路延遲，不能直接當作有效內部思考秒數。因此上表的 30／40／50／60 秒是**研究意圖組**，不是聲稱已具備精確強制執行能力。

以實際可用服務進行時應分兩類：

1. **原生可控制計算步或推理預算的後端**：固定可控制的步數／Token 預算，並記錄觀測到的秒數。
2. **只有超時設定的後端**：不以硬中斷生成的殘缺結果冒充「完成 30 秒思考的回答」。預算內完成者記 completed；截止時未完成者記 censored／timeout 並保留為失敗或截斷紀錄。可另做安全的完成後等待測量，但不能將其假稱為強制思考時間。

只有處於**明確完成態**（模型正常結束、達到自有終止條件或有可核對的完成標記）的輸出，才進入主要的完成態答案比較；截斷率需獨立報告，不能從分母中悄悄移除。

另外將固定最大 reasoning tokens／總 Token／FLOPs（可測時）的平行實驗與上述牆鐘預算分開，以排除硬體負載差異。

## 4. 重複推理的六種模式：尤其注意「不回答」

最初構想允許第一次推理完成後不輸出給使用者，或回答後再做第二輪。這必須拆成工程可辨的模式：

| 模式 | 第 $k$ 輪可接觸的前史 | 性質 |
|---|---|---|
| C0 FRESH | 每次重新建立獨立會話；只有同一原題 | 彼此獨立的同題重新抽樣 |
| C1 REPLAY_NO_STATE | 前次執行完成，但下一次不帶前次文字、隱狀態或快取 | 就模型而言仍是新起點；僅執行日誌有輪次 |
| C2 PRIOR_ANSWER | 前次完整答案加入下一輪上下文 | 答案回饋／多輪文本條件 |
| C3 PRIOR_RESULT_HIDDEN_FROM_USER | 前次結果不顯示給使用者，但**提供模型**作為下一輪的上下文／工作記錄 | 模型有歷史，使用者不可見；不是無歷史 |
| C4 CONTINUOUS_INTERNAL | 同一推論軌跡可在正常完成後由具體後端保存、恢復可用隱狀態，再繼續運算 | 真正的狀態連續，僅能在支持且有儀器的後端聲稱 |
| C5 UNEXPOSED_INTERNAL | 前次完成後，不傳入外顯答案，但有可信的內部狀態續接接口 | 與 C3 區別；需有可驗證的隱狀態保持契約 |

若產品/API 不支持 C4／C5，須標示 **unsupported**，不得透過「請繼續想」的提示宣稱自己測到了內部場態連續。C0 與 C1 若沒有可保存歷史，也不應因執行順序不同就聲稱模型記得上一輪。

### 4.1 輪次、序列與總預算

預設試驗輪次：

$$
k\in\{1,2,3,4,5,\ldots,K\}.
$$

可先以 $K=5$ 作為規約示例，並在前導試驗後預註冊是否擴至 10 或更多輪。輪次**不等於**逐步增加的思考深度。

比較「一次 60 秒」與「兩輪各 30 秒」時，必須保留真實總計算成本、輸入重新 prefill 的開銷、答案是否回填及驗證器成本。若兩輪從頭開始，不能把它叫作 60 秒連續內部思考。

## 5. 階乘設計與防混淆的主要對照

最小因子設計：

- 推理模式：直接／顯式增加推理／後端原生 reasoning effort。
- 預算：T0、T30、T40、T50、T60（超長組可選）。
- 重複：第 1–K 次。
- 前史：至少 C0／C2／C3；C4／C5 視可用性。
- 隨機性：同條件至少多次抽樣，控制 seed 或記錄不可控性。
- 語言與內容：中文長文、英文對照、數學、程式；不把不同語言表現直接視為同一尺度。

正式實驗前需進行小型 pilot 評估可行性、成本、逾時率、評分器互評一致度，再依目標效應與統計設計估算樣本數；不能把數個演示例題當統計顯著結果。

為了不把順序效應與模型服務狀態混同，應交錯／隨機化任務與預算組的執行順序，保留部署快照、實際執行時間與 API 回傳的可用遙測。

## 6. 主要觀察量：不同答案不等於更深的表徵

### 6.1 回答差異與穩定性

定義最終答案提取器 $A(\cdot)$ 及其版本。可建立配對差異指標：

$$
D_{i,k_1,k_2}=\mathbf 1[A(R_{i,k_1})\ne A(R_{i,k_2})].
$$

此值只代表在所定義的**答案同一性規則**下不同，並不表示哪個更好。對哲學文字，不能只以字串差異計數；需分開表示結構、主張、來源支持與新假說的變化。

### 6.2 表徵結構與來源保真

候選指標包括：新覆蓋的明確條件、概念關係變化、有效反例數、與原文不一致的解釋數、明確標示的創造性延伸、跨領域映射是否通過橋接驗證。由盲評、可執行驗證與留出測試分層實施。

要避免只把「更長、更豐富、提到更多領域」當作更深的理解。

### 6.3 品質與成本

記錄至少：完成態比例、確定性任務正確率、原文忠實度、過度超譯率、無法判定率、重複錯誤率、有效新增關係占比、實際推理 Token、整體耗時、模型計算成本、工具與人工評審成本。

評分器自己不可信時，需多名獨立盲評或使用確定性 verifier；其適用邊界和錯判率要記錄，不可把「評分器認為很深」當客觀深度。

## 7. 統計與因果設計：避免把隨機取樣當場態幾何

### 7.1 零假說與比較

建議至少分開：

- $H_{0a}$：在相同模型及取樣條件下，增加推理預算對指定任務品質無效果。
- $H_{0b}$：在等總預算下，C0 的多次獨立重啟與 C2／C3 的答案歷史回填效果無差別。
- $H_{0c}$：回答結構差異可由一般取樣隨機性、輸出長度或先前文本回填解釋，沒有需要額外 DRC 機制的證據。

不能因看到 $H_{0a}$ 被拒絕，就宣稱 $H_{0c}$ 也被拒絕。品質變化與神經幾何變化的識別要求不同。

### 7.2 分析與資料切分

使用題目為配對基礎，模型／預算／輪次為重複測量；來源家族與題型作聚類，明確標記多重比較。採用預註冊主結果、效果量、95% 信賴區間與失敗／截斷分母。跨模型時分開呈現同一模型內變化與模型差異，不以模型 A 的 30 秒和模型 B 的 30 秒宣稱等算力。

### 7.3 避免評估資料污染

每個題目需要固定版本、合法來源、答案／評估器與時間切分；同一數學模板改數字的衍生族不能同時跨訓練和測試。研究人員挑選「最有意思的 X 次回答」可以作探索分析，但不能取代全體預註冊分母。

## 9. 候選觀測指標（DRC-E01–12，全部未量測）

| ID | 指標 | 最小定義 |
|---|---|---|
| DRC-E01 | 完成態回答率 | 正常完成／全部啟動試驗 |
| DRC-E02 | 逾時／截斷率 | deadline 未完成／全部試驗 |
| DRC-E03 | 同題直接／推理差異率 | 按固定答案比較器的配對差異 |
| DRC-E04 | 時間組回答差異率 | 同題、不同 budget 配對的差異 |
| DRC-E05 | 輪次差異率 | 第 1 次與第 X 次答案結構差異 |
| DRC-E06 | 前史回填效應 | C0 相對 C2、C3 的品質差 |
| DRC-E07 | 狀態連續效應 | 有真實續態能力時 C4／C5 相對無狀態組 |
| DRC-E08 | 來源忠實率 | 經有效來源驗證之主張／可判定主張 |
| DRC-E09 | 有效新結構率 | 新增且通過指定驗證的關係／全部新增關係 |
| DRC-E10 | 過度超譯率 | 無來源支持卻被當成原文主張的比例 |
| DRC-E11 | 過度推理退化率 | 前期正確、後期失正的可驗證配對比率 |
| DRC-E12 | 等總成本的效益差 | 一次長推理 vs 多輪推理之品質及成本向量 |

以上均屬**新的研究候選指標**，不加入已存在的 72 項 DAS-ARL 目錄，不假稱已經量測。

## 10. 實施順序、驗收及失敗判準

**階段 A（文檔與夾具）**：完成題目契約、模式標記、答案比較器、合成事件和統計預註冊；不執行模型。

**階段 B（黑箱模型）**：先跑 T0、T30、T40、T50、T60，對照 C0／C2／C3；依實際後端支持程度控制推理預算，不捏造模型內部狀態。

**階段 C（白箱模型）**：只有能取得可信的隱狀態和模型控制權時，才測試 C4／C5 和 DRC-03 的幾何探針。

**階段 D（跨模型與跨尺度）**：不同模型類型、中文與英文、可驗證數學與哲學文本，逐項評估泛化；不以單一成功案例取代整體結論。

**正面證據的最低門檻**：觀察到可重現、來源忠實且有效的回答結構改善，並能相對等成本獨立取樣／自我反思作出可靠比較。即便如此，也**不能直接證明內部表徵空間的特定幾何**。

**負面或未決結果**：只有回答措辭不同、答案更長但未提高品質、過多推理導致退化、無法控制時間、後端不提供續態、評分器不可靠，均須如實記錄。
