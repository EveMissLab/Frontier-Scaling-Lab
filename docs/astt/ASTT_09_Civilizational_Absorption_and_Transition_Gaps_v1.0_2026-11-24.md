# 替代速度與文明吸收速度：轉型缺口、遷移摩擦與職業重組

## Substitution Speed and Civilizational Absorption: Transition Gaps, Mobility Frictions, and Occupational Restructuring

**ASTT-09｜第三部第三篇｜2026 年 11 月 24 日**  
**作者：Neo.K｜研究協作：GPT-6.2｜EveMissLab**

## 摘要

人工智慧可以在相當短的時間內提升特定領域的功能完成度、可靠性與可部署性，但技術速度不是勞動人口、企業組織、家庭所得、專業制度與社會保障的共同調適速度。即使新技術長期創造更多工作、提高總產出或擴張人的選擇，仍不能由終點的繁榮推導所有個體都能安全地穿越過渡期。本文承接 ASTT-05 的任務至就業結果帳本、ASTT-07 的替代時代拓撲，以及 ASTT-08 的跨領域交叉加速，建立以轉型事件、待承接存量、可達職位、現金流、生計恢復及持續吸收為對象的候選分析框架。

本文提出六項條件命題：離散轉型隊列的反射公式與歷史積壓、異質區域的池化下界、可達職缺二分圖的精確缺口、無新增借貸情形下的最低過渡流動性、期末狀態與累積等待及所得損失的非等價，以及缺失追蹤下持續吸收率的銳利識別界。上述模型顯示，相同的長期替代量與吸收容量可產生不同等待暴露；總職缺數量大於待轉型人口並不保證存在可行配對；受影響者即使具備學習與遷移能力，也可能缺乏跨越過渡期間的資源；首次再就業與生活恢復、長期穩定亦須分立觀測。本文採用標準隊列、匹配與存量流量方法，不將既有數學結果冒稱為新定理；新增重點在於將其嵌入既有多層替代研究及可核查的文明承接接口。

提出 CAT-M（Civilizational Absorption and Transition Measurement）候選觀測協定，明示分析邊界、受影響人口的固定分母、技術暴露與實際轉型事件的差異、非自願離職、留任再分工、所得恢復、自營轉換、可選擇的非就業生活及重複失配。透過 ILO 的生成式 AI 職業暴露研究、OECD 的技能與職業遷移研究，以及歷史就業流量和所得損失研究，定位本篇的可檢驗假說而不將歷史估計直接外推至未來的高自主 AI 世界。本文的核心判準是：文明是否具有在技術替代發生的相應時間、地點及生活條件下，將受到衝擊的人安全地承接到可行的新狀態之能力，而不只是創造足夠多的抽象職缺。

**關鍵詞：** AI 替代光譜；文明吸收；轉型缺口；存量流量；職業遷移；勞動匹配；過渡流動性；所得傷痕；持續吸收；異質時代耦合。

# 1. 問題重述：新世界抵達，不等於每個人都能抵達

AI 替代過渡期的一個特殊之處，在於前一階段的技術瓶頸可能尚未全面普及，下一階段的能力卻已經出現。數學中的可靠解題與證明、軟體中的長時程 Agent、科學中的自動化實驗與物理世界中的機器人量產，可能以不同速度出現，並互相改寫後續能力與成本。ASTT-07 已指出，這些現象不能被一條未經定義的全球替代率曲線完整描述；ASTT-08 則進一步討論跨域回饋。

在這種世界中，某些人原本從事的工作變得不再稀缺，另一些人因掌握新的高稀缺接口而獲得巨大機會。但前者是否有足夠的時間、收入、知識、設備、權利與地域可達性轉入後者，並不是由技術本身決定的。即使原本的工作有可能被下一輪技術重新定義，個人仍需要在當下支付租金、維持照護責任及取得必要服務。技術可以迅速生成新工具；已經過去的生活時間不能以同樣方式重新生成。

傳統的二元爭論常以「AI 會造成失業」與「新科技會創造新工作」彼此對抗。然而，兩個命題可能同時成立，並不直接解答同一批工作者在特定時點的命運。新的工作可以出現在不同地區、不同產業、不同技能門檻、不同所有權結構中；其出現時間也可能比原有工作需求的減少晚。反過來，若企業保留人員、主動提供有薪學習與工作重構，原有職位甚至可以在不中斷生活的情形下完成轉型。

因此本文不以「勞動市場最後是否回到充分就業」作為唯一問題，而問：在轉型路徑尚未抵達終點時，誰必須等待、誰承擔成本、哪些轉換根本不可達，以及誰有資源安全地選擇不再以原本形式工作。

文明吸收並非把每個人強制送回勞動市場。研究者轉入高專業解讀、行政人員改為協調、工作者自主創業、原有職務縮時但生活不受損，以及自願照護、學習、退休或其他有保障的生活安排，均可能是不同的承接結果。本文僅在明確定義的轉型人口及功能契約內比較它們，不把未求職的人一律列為失敗，也不把被迫離開勞動市場自動列為成功。

ASTT-01 將可靠性與偶發能力分開；ASTT-02 討論數學研究人口的選擇機制；ASTT-03 研究知識生產、理解及解讀瓶頸；ASTT-04 分離技術可替代性與經濟採用優先級；ASTT-05 已建立任務效果、工時、職位、實際聘用及收入的分帳；ASTT-06 涉及實體設備、安全與產能；ASTT-07、08 分別研究多層可達性及跨領域加速 [I1–I4]。本篇不重做其能力測量，也不重複證明節省工時不等於裁員。

本篇的新增責任是在實際轉型事件發生後，追蹤受影響的人和組織如何穿越一系列有時間與資源限制的接口，並由隊列、網路配對、生活資源及追蹤品質構成一套可反駁的吸收判準。它也是 AIBT-08 的任務效果與收益路由、AIBT-09 的有效需求研究，以及 ASTT-10 至 12 之間的過渡接口；本輪直接讀取 ASTT-05、07、08 及系列總綱，AIBT 相關定義沿用前作已核對的關係，不宣稱重審其全部原稿。

時代拓撲論的八層狀態包含知識、驗證、技術、產品、制度、權限、社會理解與再生成。工作者的學習資格、企業的採用決策、合格工作的出現、合法執業與生活所需資源，可以分別位於不同局部時代狀態。時間序列在此只是觀測索引，並不將母框架的異質狀態壓縮成一條歷史階梯。

## 2.2 已有外部研究及限定解讀

ILO 2025 年的生成式 AI 職業暴露研究以任務層資料、專家評估及模型預測建立四級暴露分類，估計全球約四分之一工作者處於某種暴露的職業，最高級占約 3.3%；研究判斷多數職務更可能經歷轉型，而不是整體消失 [E1]。這是特定時點與方法下的暴露估計，不是已觀測的失業人口，也不能直接成為本篇隊列的到達量。

Bechichi 等人（2019）以認知與任務技能距離研究職業移動，明確區分可經再訓練而完成的轉換與兼顧所得、既有人力資本的可接受轉換 [E2]。OECD 2025 年《Skills Outlook》則討論技能需求的變動、職業成長與衰退，以及不同背景人口在機會與訓練可取得性方面的差異 [E3]。本篇採納「可行不必然可接受」的區分，但新增個人選擇、現金流、可達職缺及持續性的聯合觀測，並不將技能向量的距離直接解讀為確定轉職時間。

Hall 與 Schulhofer-Wohl（2018）的匹配效率研究說明，忽略求職者異質性及人口組成變動，可能誤判整體匹配效率 [E4]。Jacobson、LaLonde 與 Sullivan（1993）透過賓夕法尼亞州的歷史行政資料，發現高年資工作者離開困境企業後可面臨持續所得損失 [E5]。Davis 與 von Wachter（2011）利用美國 1974–2008 年社會安全紀錄，發現大型裁員事件後的所得損失具有景氣依賴性 [E6]。這些研究足以支持「就業狀態不足以表示全部調適結果」是值得研究的問題；其樣本、年代和因果設計都不等於未來 AI 引發的大規模轉型，因此本文不套用其損失係數。

## 2.3 FSL 的測量接口

# 3. 三種速度與吸收狀態的定義

## 3.1 不能直接相減的速度

令研究時點為離散期間 $t$，索引的實際長度可以是月、季或年，但同一試驗中須保持一致。先區分：

- 技術能力變動：固定契約下的可靠完成率、成本、品質與可行域改變。
- 實際採用及任務轉移：企業或個體真正改寫工作流程的事件與覆蓋量。
- 人口轉型及文明吸收：受影響的人開始需要承接、完成承接或仍有未滿足需要的狀態。

若能力指標每年提高十個百分點，而再就業人口每月增加一萬人，二者不具有相同單位，不能直接相減。替代壓力應由明確的映射或可觀測事件進入吸收帳本；相關性不自動具有 AI 因果歸因。研究可先收集同時期全部轉型事件，再區分經驗證與 AI 相關、其他原因、混合原因及未明原因。

## 3.2 轉型事件與合格承接

固定人群、地區與觀測期，定義一次轉型事件為：某人因工作功能、聘用關係、實際工時、所得或必要的工作條件發生指定變動，且依預先公布的規則需要新的承接安排。可以是在職轉換，並非必須離職；亦可包含選擇回到學校、自營、正式退休或非市場活動，但不得把自主選擇與迫於生計的退出混算。

「合格承接」是一個預先註冊的判準，而不是單純獲得任何工作。候選條件包括本人可接受的工作內容、最低收入或保障、合理工時、合法權限、安全、地理及照護可行性，並另有追蹤期限。在研究過程中若當事人改變偏好，應保留原契約及其更新紀錄；不能事後降低門檻以製造成功。

若某人多次經歷不穩定轉型，人口帳本與事件帳本須分開。本文的基準隊列先採用不重複、同時只存在一個未結案事件的簡化；後續可使用事件 ID 建立復發流量與多狀態歷史。

## 3.3 基準吸收帳本

設 $B_t$ 為第 $t$ 期終了仍未承接的事件存量，$a_t$ 為當期新增需要承接的事件數，$c_t$ 為當期在固定判準下可用的有效承接容量，$m_t$ 為當期實際完成承接數。若不考慮死亡、失聯、遷出或其他競爭退出，則有守恆式：

$$
B_t=B_{t-1}+a_t-m_t.
$$

並且

$$
0\leq m_t\leq \min\{c_t,B_{t-1}+a_t\}.
$$

在完全同質、所有等待者都可使用任何容量、當期事件先到達、服務不空轉的基準模型中，$m_t=\min\{c_t,B_{t-1}+a_t\}$。這是理想下界模型，不是所有勞動市場的實際排隊規則。若存在技能不匹配、訓練時滯、放棄或資格限制，則必須將其寫成額外狀態與有效容量，或放棄同質假設。

實際資料中另設外部退出 $x_t$、重返 $r_t$ 等事件，則可改寫成 $B_t=B_{t-1}+a_t+r_t-m_t-x_t$；退出原因須保持可識別，且單純失聯不可列入成功。在固定 cohort 分析中，跨區遷出不應自動縮小分母。

# 4. T1｜同一總量不代表同一轉型歷程

**命題（離散反射與歷史積壓）。** 在第 3 節的同質、無競爭退出、服務不空轉假設下，令 $z_t=a_t-c_t$。對 $t\geq1$，有

$$
B_t=\max\left\{0,\ B_0+\sum_{s=1}^{t}z_s,\ \max_{1\leq k<t}\sum_{s=k+1}^{t}z_s\right\}.
$$

當 $t=1$ 時，忽略空的內層最大值。特別地，

$$
B_t\geq\max\left\{0,B_0+\sum_{s=1}^{t}(a_s-c_s)\right\}.
$$

**證明。** 由守恆與服務規則，$B_t=\max\{0,B_{t-1}+z_t\}$。在 $t=1$ 時成立。若對 $t-1$ 成立，將其各最大值候選加上 $z_t$，再與零取最大，得到從初始存量累加的項、從任一中間零存量之後累加的後綴項及零項。歸納完成。下界由最大值中的兩個候選立即得到。此為標準 Lindley 型離散反射遞推的應用，而非新發明的隊列公式。

**推論（持續超載）。** 若從某期開始連續 $k$ 期都有 $a_t-c_t\geq\delta>0$，則該段積壓至少增長 $k\delta$。即便前期容量曾過剩，其未使用部分若不能儲存或改成後續服務，亦無法抵銷此結果。

## 4.1 相同總吸收容量，完全不同的生活時間

下表為四期的合成算例，單位為事件數，初始存量為零。

| 期間 | 1 | 2 | 3 | 4 | 合計 |
|---|---:|---:|---:|---:|---:|
| 可用容量 | 0 | 0 | 2 | 2 | 4 |
| 情境甲：提前到達 | 4 | 0 | 0 | 0 | 4 |
| 甲的期末積壓 | 4 | 4 | 2 | 0 | 10（事件期） |
| 情境乙：同步到達 | 0 | 0 | 2 | 2 | 4 |
| 乙的期末積壓 | 0 | 0 | 0 | 0 | 0（事件期） |

兩個世界的總到達、總容量及末期積壓完全相同，但甲多出十個期末積壓事件期。若期間為月，這代表離散觀測下十個人月等價的等待暴露，並不必然等於精確日數。期末無積壓無法取消已發生的等待。反過來，若容量集中於到達前且無法儲存，也可能在總容量足夠時仍留下期末積壓。

因此本文建議同時保留峰值 $B_{\max}=\max_t B_t$、離散累積暴露 $W=\sum_t B_t\Delta t$、清理時間及不同人群的等待分布。$W$ 的量綱是事件乘時間；它不能直接當作貨幣損失，因各人的現金流、所得與保障可能不同。

**界線。** 容量若可跨期預付或儲存、允許預防性承接、到達在服務之後、或具有多人多次事件與不同服務時長，應另建模型。這個反射公式不是對現實待業時間的估計。

# 5. T2｜文明的總容量充足，不代表局部世界能吸收

**命題（異質分區與池化下界）。** 將待承接事件分為 $g=1,\ldots,G$ 個不能即時互換容量的群組。在各群皆符合 T1 的基準假設時，令

$$
B_{g,t}=\max\{0,B_{g,t-1}+a_{g,t}-c_{g,t}\}.
$$

另構造一個完全可共享容量、總到達及總初始存量相同的理想池化隊列 $B_t^{\mathrm{pool}}$，則每一期均有

$$
\sum_g B_{g,t}\geq B_t^{\mathrm{pool}}.
$$

對同一組期初局部存量，定義 $v_g=B_{g,t-1}+a_{g,t}-c_{g,t}$，$P=\sum_g\max(v_g,0)$，$U=\sum_g\max(-v_g,0)$。相較於立即共享該期未用容量的單步反事實，局部積壓超出量恰為

$$
P-\max\{0,\sum_g v_g\}=\min\{P,U\}.
$$

**證明。** 由 $\sum_g v_g=P-U$，單步差為 $P-\max(0,P-U)$，依 $P\geq U$ 或 $P<U$ 分別得到 $U$ 或 $P$。多期情形，假定上期局部存量合計不小於池化存量。以正部函數的單調性及 $\sum_g\max(0,v_g)\geq\max(0,\sum_g v_g)$，可推出下一期仍然成立；初始相同，因此歸納成立。

## 5.1 局部時代錯位的意義

假設地區甲有十名需要轉型的人與兩個合格職缺，乙有兩名需轉型的人及十個職缺，且沒有可以即時跨區工作的條件。總計十二人及十二職缺，實際卻可能留下八人等待與八個職缺閒置。這個差額不是因為人不努力，也不是因為工作總量必然不足，而是接口尚未建立。

在實際社會中，地理遷移、居住費用、語言、照護、簽證、資格、網路、雇主政策與職業偏好都可能阻止即時池化。同一公司的兩個部門也可能因為責任與知識不可互換而呈現類似問題。反過來，遠端工作、資格互認、公共交通、工作重新設計或 AI 輔助可以減少某些摩擦。是否有效要以實際合格承接與成本觀測，而非僅看容量是否被重新標示為可共享。

**界線。** 理想池化只是比較基準，並不表示所有人應跨區流動或放棄偏好。若池化本身使服務品質下降、增加等待、出現隱私或合法性問題，就不能以同一容量假設聲稱它必然改善福利。單步差額也不是多期因果損失的直接加總，因為兩條歷史的期初狀態逐漸不同。

# 6. T3｜職缺多於人口，仍可能存在不可消除的匹配缺口

## 6.1 將異質可達性寫成二分圖

考慮某個決策時點的有限人口集合 $U$ 與可在指定期限內開始的合格工作槽集合 $V$。一個槽表示一個不重複的可聘用位置；多個位置可以拆成多個槽。建立邊集 $E\subseteq U\times V$，當且僅當該人與職缺在固定期限及契約下存在可行且可接受的轉換。邊可以依技能、證照、地區、待遇、工時、成本、職缺有效期限、當事人選擇及必要訓練判斷。

此處的邊是條件化的可行性，不是保證企業會聘用某人。真實職位若競爭、資訊不完全或受歧視影響，實際配對可以少於理想最大匹配；尚未查證的邊需列為未知，而非直接當成不可達。

**命題（最大匹配與集合缺口）。** 令 $\nu(G)$ 為二分圖的最大匹配大小，$N(S)$ 為 $S\subseteq U$ 的鄰接槽集合。則有

$$
|U|-\nu(G)=\max_{S\subseteq U}\left(|S|-|N(S)|\right).
$$

右側包含空集合，所以非負。所有人都能在這個理想圖上同時被吸收，當且僅當每個 $S\subseteq U$ 均滿足 $|N(S)|\geq|S|$。

**證明。** 任意匹配中，$S$ 至多有 $|N(S)|$ 人被配對，因此未配對總數至少是右側。反向，令右側最大值為 $d$，新增 $d$ 個可與所有 $U$ 相連的虛擬槽。對每個非空 $S$，新鄰域大小為 $|N(S)|+d\geq|S|$。由 Hall 婚配定理，擴充圖存在覆蓋全體 $U$ 的匹配。移除虛擬槽後至少留下 $|U|-d$ 個原圖配對，得到另一方向不等式。證畢。這是標準 Hall 缺額公式；本文的貢獻是轉型契約及證據語義，而非定理本身。

## 6.2 從總數幻象到職業重組

合成例：三人甲、乙、丙及三個職缺 A、B、C。甲和乙只可接受 A，丙可接受 B 或 C。雖然每人至少有一個可達職缺，總職缺也與人口數相等，但甲乙集合的鄰域只有一個槽，故至少一人無法同時完成匹配。若再增加與丙相容的職缺，仍不解決甲乙的瓶頸。

這個結構可以套用到數學研究人員的再分工：新的深度解讀、跨域橋接與科學應用工作可能具有很高價值，但它們的數量、入場門檻、研究資源及適配的個人能力不必恰好符合原有研究人口。不能從「有新工作」推導「所有人都有新工作」，也不能因此否定新職能本身的價值。

同一 AI 系統也可能同時為原有職務增加新任務並壓縮其他職務。若把同一家企業內部工作重構建為留任槽，將自營方案建為具有市場、資金和許可的候選轉換，將自願非就業安排另列為有保障的承接狀態，就可以保留多種選擇，而不把所有人強制放入同一求職圖。多期問題必須追蹤職缺有效期限、訓練延遲與共享資源；單期最大匹配不是長期均衡。

## 6.3 證據不完備時的兩張圖

令 $E^-$ 為有充分證據的可行邊，$E^+$ 為在現有證據與限制下尚未排除的候選邊，且真正邊集被這兩者包含：$E^-\subseteq E\subseteq E^+$。由最大匹配對加邊的單調性，

$$
|U|-\nu(U,V,E^+)\leq |U|-\nu(U,V,E)\leq |U|-\nu(U,V,E^-).
$$

只有在工作槽集合、評價期限與共同契約固定，且這兩個包含關係有合理依據時，此區間才有意義。它防止將尚未測量的資格或職缺相容性當作零或肯定存在。

# 7. T4｜能學會，不等於付得起學會之前的生活

## 7.1 過渡流動性

一個人可能有技術上的再學習能力，卻因為停薪、訓練費、租金、必要交通、照護或醫療支出而無法完成轉換。此處不以個人道德或學習意願解釋資源不足，而建立可檢驗的流動性帳本。

在固定轉換路徑中，令 $b_0\geq0$ 為初始可動用現金及等價流動資源；$i_t\geq0$ 為當期實際可動用的收入、補助等流入；$o_t\geq0$ 為當期必要生活與轉換支出。假設當期流量可以先淨額結算、所有期間末現金均須非負、無利息及新增借貸，且在起點一次性提供額外橋接資金 $g\geq0$。因此

$$
b_t=b_0+g+\sum_{s=1}^{t}(i_s-o_s).
$$

**命題（最小橋接流動性）。** 在上述假設下，完成指定現金流路徑所需的最小起點額外資金為

$$
g^*=\max\left\{0,\max_{1\leq t\leq T}\left[\sum_{s=1}^{t}(o_s-i_s)-b_0\right]\right\}.
$$

**證明。** 每個期間末非負等價於 $g\geq\sum_{s=1}^{t}(o_s-i_s)-b_0$。與 $g\geq0$ 共同取最嚴格的下界即為所求，該下界同時滿足所有限制，故具有必要性及充分性。

## 7.2 轉型成本與現金流不是同一個量

合成例：三個月的支出各為 2 萬元，流入分別為 0、0、6 萬元，初始現金為零。整段淨收支恰好平衡，但前兩個月累積缺口達 4 萬元；若只在第三個月獲得工作所得，無法以其未來收入直接支付此前的租金。若把同額流入改成每月 2 萬元，最低橋接資金則為零。

這一簡單結果具有制度意義：一個長期可能成功的轉職方案，如果中途無法維持生活，就不是真正可達的方案。增加訓練名額不一定解除現金流限制；反過來，無針對性的現金補助也不能自動創造可接受的工作槽。學習容量、技能匹配及生計承接是不同接口。

模型亦可計算未來某段收入不確定下的情境橋接上界與風險，但不能把預期收入視為已到帳現金。借貸須列還款、利息、抵押及風險；資產出售須考慮時間與價格；若流出早於流入，必須提高觀測時間解析度，或要求逐筆交易前綴皆可支付。

**界線。** 此命題是會計可行性，不保證生活品質或長期收益。它不適用於任意信用授信、重大隨機事件或福利資格內生改變的世界；也不是對任何人的財務建議。

# 8. T5｜期末就業恢復，不能取消過去的等待與所得損失

## 8.1 固定人口的事件期核算

令 $U_0$ 為固定觀測群體，$w_{i,t}\in\{0,1\}$ 表示第 $t$ 期期末個體 $i$ 是否仍處於指定的未承接狀態。在完整、相同頻率的追蹤中，定義

$$
B_t=\sum_{i\in U_0}w_{i,t},\qquad W=\sum_{t=1}^{T}B_t\Delta t.
$$

**命題（人期守恆及所得路徑非等價）。** 有

$$
W=\sum_{i\in U_0}\sum_{t=1}^{T}w_{i,t}\Delta t.
$$

若 $y^0_{i,t}$ 為事前指定的比較所得、$y_{i,t}$ 為實際勞動所得，則有精確分解

$$
L_i=\sum_{t=1}^{T}(y^0_{i,t}-y_{i,t})
=\sum_{t:w_{i,t}=1}(y^0_{i,t}-y_{i,t})+\sum_{t:w_{i,t}=0}(y^0_{i,t}-y_{i,t}).
$$

因此終點 $B_T$ 不足以辨識 $W$ 或 $L_i$；首次再就業亦不足以辨識後續所得損失。

**證明。** 第一式交換有限求和次序；第二式按互斥且完備的狀態分割期間。非辨識性見以下具有相同終點的反例。這些是會計恆等式，不是對未觀測反事實所得的因果估計。

## 8.2 兩條等終點路徑

某人三期比較所得皆為 100（示意貨幣單位），情境甲三期實際所得為 0、50、100，未承接狀態為 1、0、0；情境乙三期實際所得為 100、100、100，未承接狀態均為零。兩者最後一期都具有工作且所得為 100。甲卻累積 150 的比較所得差，其中 100 發生在未承接期，50 發生於已重新就業後。若換成甲在前兩期都未承接，等待暴露也更大，即使終點相同。

$L_i$ 是帶正負號的淨差，後來較高的所得可抵銷早期差額。若要研究曾經遭遇的收入缺口，另定義

$$
L_i^+=\sum_t\max\{y^0_{i,t}-y_{i,t},0\}.
$$

兩者不可混用。若研究家庭可支配資源，則需另外加入非勞動所得、稅、移轉與轉換支出，不能直接用勞動所得差代表家庭生活損失。因果推斷還需識別比較所得 $y^0_{i,t}$：受影響前收入、適當對照組或結構模型都可能是候選，但各自帶有假設。不能把前期固定工資直接聲稱為已證明的未採用 AI 反事實。

## 8.3 為什麼現代文明不能只展示終點

如果技術使總體產出提高而轉換者在此前數個月無法付費、延後治療或被迫放棄照護安排，即使總體所得後來恢復，部分不可逆的生活後果仍可能存在。另一方面，若工作者自願縮短工時且透過公共服務、家庭選擇或其他收入保持生活條件，工資下降不必然意味福利下降。應將這些路徑分帳，而不是建立單一「回到工作」成敗敘事。

**界線。** 本節只核算已定義且完整觀測的狀態與貨幣流量。不將主觀滿意、自由時間、家庭關係、健康或尊嚴直接貨幣化。不同觀測時距的短暫未承接期可能被漏掉，須依事件日期修正。

# 9. T6｜首次轉型成功、持續吸收與缺失追蹤

## 9.1 動態目的地與反覆轉型

AI 技術的交叉加速可能讓工作者剛完成某項技能訓練，所欲進入的工作內容又發生改變。因此吸收是一條可能重新開啟的路徑，而不是不可逆的終點。當期有一個可用的訓練方案，不代表數個月後仍有同一批職缺；反覆進入短暫職位也不代表已建立穩定生活。

建立兩個分開的指標：在預先指定期限內第一次達到承接條件的比例，以及在第一次承接後持續滿足條件達 $h$ 期的比例。第二個指標必須同時具備固定 cohort、起算日期、觀察截止日、可接受的短期中斷規則及完整追蹤。如果人員轉入新的合格工作，可依事前規則保持吸收狀態，而非機械地要求同一雇主。若無足夠後續觀測，應標為未知。

**命題（缺失追蹤下的銳利界）。** 對固定的 $N>0$ 個目標個體，設定一個已明確定義的二元持續吸收結果。令 $n_1$ 為已確認成功的人數，$n_0$ 為已確認失敗的人數，$n_?$ 為尚無法判定的人數，三者之和為 $N$。在不額外假設缺失機制且不改變分母時，真實比例 $p$ 的識別界為

$$
\frac{n_1}{N}\leq p\leq\frac{n_1+n_?}{N}.
$$

**證明。** 每個未知結果只可能是零或一。因此未知成功數最小為零、最大為 $n_?$。取所有未知皆失敗與皆成功分別達到兩端，故在無額外限制下為銳利界。證畢。這是標準的最壞情形缺失值界，並非統計信賴區間。

例如固定追蹤 100 人，60 人確認成功、20 人確認失敗、20 人尚未知，則吸收率在 60% 至 80% 之間，而不是直接報告完整個案的 75% 作為整體比例。若某些人追蹤期尚未結束，未知的性質需標為右設限；若某人死亡或自願退出而使原結果無法定義，應事前規範競爭事件與估計對象，不可事後任意分配為成功或失敗。

## 9.2 制度承接也有記憶與退化

新技能可能貶值，新的工作可能消失，補助可能到期，照護條件亦會變更。制度吸收容量不是固定常數：它可以因訓練人力、住房、資金、組織變革、社會信任、基礎設施、法律與可用 AI 而增加或減少。對同一人反覆發生的事件，既要報告不重複人口，也要報告事件頻率和間隔。僅計首次成功可能誤把高頻短期配對市場呈現為高吸收能力；僅計持續工作又可能忽略自願多樣化生活。

**界線。** 真實追蹤存在錯誤分類、共同衝擊及其他競爭事件時，需增加相應假設及敏感度分析。未觀測不是失敗，未知上界也不是預測。此命題不保證有足夠資料將區間縮窄。

# 10. 吸收能力是耦合狀態，而不是一個常數

六項命題共同展示：新增需要承接的人口、有效容量、等待、匹配、資源及持續性不能壓成單一百分比。本篇將吸收狀態定義為一組具有明確量綱的觀測座標：

$$
\mathcal A_{g,t}=(B_{g,t},a_{g,t},m_{g,t},C_{g,t},\mathcal G_{g,t},\mathcal L_{g,t},\mathcal Y_{g,t},\mathcal D_{g,t}).
$$

其中 $C$ 為可用承接容量及證據，$\mathcal G$ 為可達轉換網路，$\mathcal L$ 為流動性與生活資源分布，$\mathcal Y$ 為所得與其他生活條件路徑，$\mathcal D$ 為持續承接與追蹤狀態。它是 ASTT 的候選局部資料型別，不取代母框架的八層時代狀態，也不直接套入 FSL 的 224 個能力指標。各組分量具有不同量綱，禁止簡單加總。

吸收容量可能包含幾個彼此制約的階段：發現可行目的地、取得訓練及證照、維持生活、實際進入新工作或新生活狀態、穩定留存。若把這些階段視為同一批人的序列，各階段的通過比例必須以相同 cohort 及明確條件計算。例如 $P(\text{留存})=P(\text{首次承接})P(\text{留存}\mid\text{首次承接})$，只在留存定義確實包含首次承接時才適用；不應相乘來自不同來源、時點及分母的平均成功率。

技術替代可以增加到達量 $a$，也可以提高容量 $C$、新增配對邊、降低訓練時間及減少轉換費用；它亦可能減少原本可接受的職缺、使某些既有邊失效或增加照護與驗收責任。故 AI 可能同時是衝擊來源與調適工具。其淨作用依局部世界而異，不能先驗宣告為必然的失業機器或必然的職位創造機器。

當一個地區或領域的替代壓力向另一地區傳遞時，還可能形成二階效應：被壓縮的專業人口進入原先低替代的服務市場，增加該市場的勞動供給；若新需求沒有同步增加，報酬及議價能力可能改變。這並不代表所有服務業收入必然下降，因為需求擴張、技能互補、地域與制度仍可產生反向結果。測量必須觀察實際跨域流量、職缺變動、工時及薪酬，而非將遷移假設當作觀測結果。

# 11. 四種過渡情境及人口的異質承接

| 情境 | 主要條件 | 可觀測的可能結果 | 不可直接推出 |
|---|---|---|---|
| 同步增強 | 原有組織留任，工作重構與學習安排足夠 | 工作內容改變，所得中斷較小 | 所有人均得到增益 |
| 產能先行 | 任務與職位迅速壓縮，目的地較晚出現 | 積壓、等待、流動性缺口 | 永久失業 |
| 局部稀缺 | 新工作很多，但集中在難以進入的領域、地區或權限 | 空缺與未承接人口並存 | 工作者缺乏能力或意願 |
| 多路承接 | 有可接受工作、創業、學習或有保障的非就業生活 | 轉型目的地多樣化 | 不需要財源、需求或制度治理 |

這些情境不是互斥的全球歷史預言。同一家公司內部可能同時有留任增強及人力壓縮，同一城市內可以出現高技能轉型與低收入壓力。某個高收入專業者可能因資產、可移轉技能和人脈而迅速調適；另一個具同等能力的人可能因家庭責任而不具相同可達性。也不能把低收入人口普遍描述成容易失敗：接近新需求的工作位置、社會網路及低轉換成本都可能使其更具韌性。

因此，研究應區分四個層次的時間：技術版本及工作流程的時間、企業投資及人員調整時間、個人及家庭的轉換時間、制度立法及執行時間。這些時間有交叉依賴，沒有一個固定比例。以週計的軟體部署可以與以年計的專業執業資格共存；某項制度改革又可能快速解除前述瓶頸，讓原本不可能的轉換變成可行。ASTT-07 的有向可達性可以將這些變化建成版本化轉換圖，ASTT-08 則提供研究跨域加速與回饋的機制。

## 11.1 預防式轉換與保留選擇權

若可以在原有職務仍存在時開始訓練與工作重構，則部分到達量有可能從「失去工作後才開始等待」改成「尚有收入時完成轉換」。在模型中應另外記錄預防性事件，不可為了降低失業統計而忽略被迫減薪或無償學習成本。預防式安排的價值在於縮短真實的未承接暴露、降低生活缺口及保留當事人選擇，而不是凍結所有既有工作。

## 11.2 吸收不等於替人決定生活

制度可以提高可達選項集合，例如提供公共工具、轉換保障、資格承認及工作安排，但不應因此把人視為必須最大化就業率的待分配物件。不同人對職業身份、照護、創造、學習與休閒的偏好不同；即使某人不願前往在經濟上最有利的職位，也不能自動視為文明吸收失敗。可接受契約與基本權利應成為模型的一部分，不是匹配演算法完成後才補上的例外。

## 12.2 最小研究設計

先在一個可辨識任務域定義受影響群體及不受影響的適當比較群體，封存任務契約、AI 採用事件、轉型判準、時間尺度、資料使用權與追蹤規則。以採用前歷史、分批部署或其他可信識別設計估計工作變化，而非使用簡單前後差直接宣告 AI 因果效果。若不同組織採用時間差異與經營困境同時發生，應測試共同趨勢、選擇偏差、預期效應與外溢；不符合假設時報告描述性結果。

對每個固定 cohort 收集等期資料並另存事件時間戳，維持不重複分母。預註冊至少一個首次承接期限及一個持續承接期限，並公布未知原因、轉出與復發。將實際職缺及可行訓練與工作者條件匹配，但只使用必要、合法、同意的資料；不得用模型推測敏感人口特徵、健康狀態或個人價值。研究結果優先採用匯總及去識別化形式，防止小樣本反識別。工作條件與所得的個體資料不得因公開研究而失去保護。

# 13. 六項可否證假說及候選識別設計

以下假說是條件性、尚未實測的方向性研究主張，不能把有限模型驗算當成它們的證據。

| ID | 可檢驗假說 | 觀測設計與否證條件 |
|---|---|---|
| H1 | 在相似總衝擊量及容量下，集中到達且承接延後的群體，具有較大累積等待暴露 | 依真實採用及轉型事件時間配對比較；若延後群體的等待在控制預防式安排後未增加，該方向不獲支持 |
| H2 | 跨區資格、交通或遠端工具解除特定摩擦後，在相似需求及品質門檻下，局部未承接和閒置職缺的共存下降 | 在制度實施前後以適當對照群及外溢檢查估計；若只增加名義職缺或降低品質、可行配對未改善，不能支持假說 |
| H3 | 以實際可達性、共同容量與接受條件構造的配對網路，比單純職缺人口比更能預測固定期限內未承接結果 | 封存兩種預測及樣本外結果；若圖模型未改善預測或資料成本過高，其新增價值未成立 |
| H4 | 在訓練、需求和接受條件相近的群體中，解除前綴現金缺口的支持能提高完成轉型比例 | 比較有識別力的補助時點差異及實際到帳；若缺口解除但完成率沒有改善，流動性可能並非主要瓶頸 |
| H5 | 相同末期就業率的群體可具有顯著不同的等待人期及所得路徑；早期承接可能降低其中部分損失 | 追蹤相同固定 cohort、校正比較所得及工作品質；若實際路徑差異很小，不能主張該情境存在重大過程缺口 |
| H6 | 在需求頻繁變動的領域，首次承接率與持續承接率的差距可能大於相似但穩定的領域 | 固定追蹤窗、處理復發與設限，估計結果區間；若差距沒有擴大或缺失界無法區分，不能證成假說 |

應注意，H1 與 T1 的關係是由簡化模型提出待驗現實機制，而不是推導所有現實隊列必然具有該方向。T3 的 Hall 界在固定圖上成立，但 H3 檢驗的是這個圖是否有效表示現實相容性。T4 的會計條件也不保證提高資助就能使每個人成功。因果研究需分辨衝擊時點、職位創造時點、選擇進入樣本及其他宏觀變動。

# 14. 從第三部走向殘餘稀缺性槓桿

ASTT-07 將替代建模為異質時代狀態的可達性；ASTT-08 研究不同域如何互相加速及受限；ASTT-09 則建立人口與制度是否能穿越這些狀態的觀測接口。三者共同形成：技術前沿的移動、跨域實現速度、生活與制度承接速度三條不等價的歷史路徑。

若大量普通的知識和任務能力變得廉價，但少數高專業解讀、實驗資源、製造能力、住房、合法權限、資本及分配通道仍然稀缺，某些關鍵接口可能具有超比例經濟槓桿。此時，擁有資源的人不只較容易得到新技術的紅利，也可能較容易支付轉換期間的前綴缺口、取得新資格及等待更高品質的機會；其餘人口則可能因流動性不足接受較差條件。這種機會差異不等於能力本身的差異。

然而，積壓或匹配缺口本身不能證明有人取得壟斷租金，更不能證明所有稀缺接口的收益都不正當。需要另外識別所有權、競爭、替代路徑、需求、真實交易價格與外部性。這是下一篇 ASTT-10 的責任。本篇只提供進入經濟槓桿的異質承接狀態，並提醒不能以短期瓶頸推導永久不可替代。

制度方向亦不只有抑制技術發展或要求所有人迅速轉職。可評估的選擇包括事前工作重構、有薪學習、可攜資格、跨區服務、公共智能工具、過渡生活保障、分享生產力紅利以及多元工作和非工作選項。它們需要不同的財源、執行條件與治理機制，可能具有替代或互補關係；本篇不假定任何一項已被證明為最優制度。即使吸收速度提高，也仍須獨立檢驗文明淨利益及分配結果，不得以 SAS-01 的系統再生門檻代替文明正和門檻。

# 15. 結論：文明的速度，不能只由抵達前沿的人決定

AI 可能讓社會比以往更快取得可靠知識、製造實體成果、改寫工作方式及創造新的經濟活動；同時也可能讓原有職業及生活結構快速改變。真正重要的不是預先相信所有人終將失業或所有人終將被新工作吸收，而是理解這些變化如何透過不同時間、地區、技能、資源及制度接口傳遞。

技術替代的總量與文明吸收的總容量不能充分解釋過程；同一批人在同一時刻的可達選擇才是局部轉型能否完成的重要條件。未使用的昨日職缺不一定能承接明日的人，總數充足的今天也可能存在局部匹配缺口。即使再就業最終恢復，過去的等待、所得與生活變化仍需要被看見。首次成功與持續成功更不是同一概念。

本文未提出一個文明統一時鐘，也沒有給出未來全球替代或吸收的百分比。它提出的是在明確條件下可被計算、驗證、反駁及更新的過渡期分析方法。是否有更快、更低成本且尊重選擇的承接路徑，必須透過真實制度、真實人群與真實時間來驗證。

人類不需要以永久的功能不可替代性換取生活權；文明也不能因技術上已經找到替代方案，就認為所有受影響的人都已獲得新的可行人生。

**未來抵達得有多快，是技術的問題；有多少人能以自己的選擇安全地抵達，才是文明的問題。**

## 附錄 B｜可重播有限模型與收據

以下標準函式庫 Python 程式用於精確的有限模型一致性檢查；全部是合成配置，無真實人口或企業資料。T1 驗證反射公式；T2 驗證單步池化差額與多期下界；T3 以排列枚舉與鄰域子集枚舉交叉比對；T4 以最低資金的離散暴力搜尋核查前綴公式；T5 檢查等待區間與所得分帳；T6 枚舉未知結果的全部二元補全。固定示例另列，不計入配置數。

以 Python 3.10 以上執行。從下方程式碼區塊擷取原始 Python 程式為 `replay.py`，執行 `python replay.py`；不需網路或第三方套件。程式測試不是對無限模型的證明，數學證明已於正文列出。

```python
from itertools import product, permutations
from collections import Counter
from fractions import Fraction

counts = Counter()

def queue(b, arrivals, caps):
    hist = []
    for a, c in zip(arrivals, caps):
        b = max(0, b + a - c)
        hist.append(b)
    return hist

# T1: reflection formula, terminal bound, conservation, no hidden negative backlog.
for b0 in range(3):
    for a in product(range(3), repeat=4):
        for c in product(range(3), repeat=4):
            b = queue(b0, a, c)
            prev = b0
            for t, v in enumerate(b, 1):
                z = [a[i] - c[i] for i in range(t)]
                formula = max([0, b0 + sum(z)] + [sum(z[k:]) for k in range(1, t)])
                assert v == formula
                absorbed = prev + a[t-1] - v
                assert 0 <= absorbed <= c[t-1] and absorbed <= prev + a[t-1]
                prev = v
            assert b[-1] >= max(0, b0 + sum(a) - sum(c))
            counts['T1'] += 1

# T2: separate regional queues vs a frictionless pool; one-step pooling gap.
for b1, b2 in product(range(2), repeat=2):
    for x in product(range(2), repeat=12):
        a1, a2, c1, c2 = [x[k:k+3] for k in range(0, 12, 3)]
        h1, h2 = queue(b1, a1, c1), queue(b2, a2, c2)
        hp = queue(b1+b2, [i+j for i,j in zip(a1,a2)], [i+j for i,j in zip(c1,c2)])
        prev1, prev2 = b1, b2
        for t in range(3):
            n = [prev1+a1[t]-c1[t], prev2+a2[t]-c2[t]]
            p = sum(max(v, 0) for v in n)
            u = sum(max(-v, 0) for v in n)
            assert h1[t]+h2[t]-max(0,sum(n)) == min(p,u)
            assert h1[t]+h2[t] >= hp[t]
            prev1, prev2 = h1[t], h2[t]
        counts['T2'] += 1

# T3: maximum matching vs Hall deficiency. Exact brute force, independent of subset test.
def match_size(rows, m):
    n = len(rows)
    for k in range(min(n,m), -1, -1):
        for left in permutations(range(n), k):
            for right in permutations(range(m), k):
                if all(rows[i] & (1 << j) for i, j in zip(left, right)):
                    return k
    raise AssertionError('empty matching must exist')

def deficiency(rows):
    n = len(rows)
    result = 0
    for mask in range(1 << n):
        neigh = 0
        for i, row in enumerate(rows):
            if mask & (1 << i):
                neigh |= row
        result = max(result, mask.bit_count()-neigh.bit_count())
    return result

for n,m in [(3,3), (3,4), (4,3)]:
    for rows in product(range(1 << m), repeat=n):
        assert n-match_size(rows,m) == deficiency(rows)
        counts['T3'] += 1

# T4: minimum liquid bridge under the specified end-of-period cash netting convention.
for inflow in product(range(3), repeat=4):
    for outflow in product(range(3), repeat=4):
        need = max([0]+[sum(outflow[:k])-sum(inflow[:k]) for k in range(1,5)])
        brute = None
        for bridge in range(sum(outflow)+1):
            cash = bridge
            ok = True
            for i,o in zip(inflow,outflow):
                cash += i-o
                ok = ok and cash >= 0
            if ok:
                brute = bridge
                break
        assert need == brute
        for initial in range(5):
            assert max(0, need-initial) == next(k for k in range(sum(outflow)+1) if initial+k >= brute)
            counts['T4'] += 1

# T5: cohort person-period accounting and signed earnings decomposition.
# state: 0 unsettled, 1 settled lower earnings, 2 settled parity, 3 settled higher earnings
for hist in product(range(4), repeat=6):
    for base in (2,3,5):
        actual = [0 if s==0 else base-1 if s==1 else base if s==2 else base+2 for s in hist]
        a = sum(base-y for y in actual)
        absent = sum(base for s in hist if s==0)
        post = sum(base-y for s,y in zip(hist,actual) if s!=0)
        assert a == absent+post
        spells = []
        start = None
        for i,s in enumerate(hist+(1,)):
            if s==0 and start is None:
                start=i
            elif s!=0 and start is not None:
                spells.append((start,i)); start=None
        assert sum(s==0 for s in hist) == sum(e-b for b,e in spells)
        counts['T5'] += 1

# T6: sharp fixed-cohort bounds with missing durable-settlement outcomes.
# -1 unknown, 0 observed failure, 1 observed success.
for n in range(1,8):
    for y in product((-1,0,1),repeat=n):
        known = y.count(1)
        unknown = y.count(-1)
        feasible = [Fraction(known+sum(z),n) for z in product((0,1),repeat=unknown)]
        assert min(feasible) == Fraction(known,n)
        assert max(feasible) == Fraction(known+unknown,n)
        counts['T6'] += 1

# Fixed illustrative regressions (not additional configurations).
assert queue(0,[4,0,0,0],[0,0,2,2]) == [4,4,2,0]
assert queue(0,[0,0,2,2],[0,0,2,2]) == [0,0,0,0]
assert match_size((1,1,6),3) == 2
assert queue(0,[4,4,4],[2,2,2]) == [2,4,6]
assert (sum([6,0,0]), sum([0,0,6])) == (6,6)
for name in sorted(counts):
    print(f'{name}: {counts[name]}')
print('TOTAL:',sum(counts.values()))
print('PASS: all finite configurations and fixed regressions')
```
