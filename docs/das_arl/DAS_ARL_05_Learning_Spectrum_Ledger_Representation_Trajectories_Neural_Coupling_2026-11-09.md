# 學習光譜帳本、表徵歷程與神經網路聯動：深度注意力學習的可觀測性、溯源與因果識別

## 摘要

深度注意力光譜（Deep Attention Spectrum, DAS）研究相同來源資訊在不同認知操作、表徵狀態與驗證條件下，能否產生有效而可檢查的重新理解；深度注意力學習（DAS-L）進一步研究模型如何學會自主選擇這些操作。本系列前四篇已界定問題本體、動態控制、同域／跨域雙層路由及可微與不可微的訓練接口。然而，僅憑輸出的正確與否或累計訓練步數，無法回答：某來源究竟被接觸、檢索、運算、重建或重新學習多少次？一次專家調用是否與該來源有關？某個神經網路區域的活化、梯度或參數變化，是否足以證明該來源導致知識形成？

本文提出**深度注意力學習光譜帳本**（Deep Attention Spectrum Learning Ledger, DAS-LL）作為一項候選可審計資料規約：以來源版本、任務契約、事件型別、執行時鐘、模型檢查點、表徵產生／驗證憑證、神經遙測與成本向量建立多層事件圖；在此圖上定義互不混淆的計數、可觀測性分級及不可識別的邊界。本文區分「事件參與」、「梯度貢獻估計」、「對神經活動的干預影響」與「跨任務能力形成」四種不同強度的結論，明確指出事件追溯不蘊涵因果歸因、參數位移不蘊涵知識習得、注意力權重不等於解釋、成功檢索不等於模型權重保存知識。文中提出五項條件性命題，搭配可重播的合成 JSONL 事件、資料契約、確定性測試與二十項未量測的 Frontier-Scaling-Lab 候選指標。

本文的貢獻是把「AI 過去究竟如何處理同一資訊」轉化為**可部分觀測、可檢查來源與版本、可誠實記錄未知**的研究議題，而非宣稱可以完整讀出任意模型的內在知識地圖。所有合成例子只檢驗記錄規則和條件性形式結論，不能被描述為 DAS-L 真實模型訓練效果。第六篇將依此規約對數學、程式與 Agent 任務建立外部有效性與成本的實驗基準。

**關鍵詞**：深度注意力光譜；DAS-L；DAS-LL；學習事件帳本；資料溯源；表徵歷程；神經因果歸因；檢查點；持續學習；可觀測性；遺忘事件；成本歸因。

## 1. 問題起點：AI「學過」某份資料究竟是什麼意思？

### 1.1 同一資訊可能具有多種事件歷史

一個 AI 系統可以在資料匯入階段接觸到某篇文章，於訓練時以不同位置的片段進行前向與反向運算，在某次參數更新中以極小的梯度權重參與優化，於推論時再由檢索工具讀到該文，又在另一個任務中使用該文衍生的摘要。這些歷史不構成單一可互換的「學過五次」。

同樣地，一個模型可能在未更新任何權重時，因多次表徵重建而取得較好的數學解答；也可能在更新參數之後，仍未保留該題的正確解法。前者屬推論時的工作狀態變化，後者才有訓練事件，但兩者均須以外部測試檢查實際能力。將兩者混在一起，會導致研究者高估訓練量、低估外部資訊注入，甚至把使用者反覆解釋的成本錯算成模型自主能力。

本研究特別關心五個問題：**同一來源被真正接觸幾次、由哪些程序處理、產生哪些表徵路徑、與哪些模組或專家有關、最後對外部可驗證能力有何影響**。前四項可透過適當的記錄系統取得局部答案；第五項往往需要介入式或比較式實驗，不能從記錄自動推導。

### 1.2 問題不是替大模型建立擬人化記憶日記

DAS-LL 的「帳本」並非意識報告、自我敘事、心理狀態自述或對單個神經元的人格化命名。它是研究者可查核的**資料處理與表徵實驗憑證系統**。從模型自述「我記得這個」無法確認訓練事件；從儲存的完整提示詞也不能確認模型確實將其作為有效推理依據；從神經元活化更不能直推某項知識已永久寫入權重。

本文採取可否證的最小承諾：只記錄可觀察事件；對依賴模型內部推斷的連結明確標記估計；對不可觀察情形回傳 `unknown`、`not_observed` 或 `not_applicable`，而非補出理想化數字。

## 2. 與前四篇的理論接口

第一篇區分來源接觸、理解與有效重構；第二篇定義固定來源下的狀態、驗證契約和停止機制；第三篇將認知操作路由與 MoE 計算路由分開；第四篇建立固定步數循環、控制策略、外部驗證及梯度更新的不同訓練接口。本篇不改寫這些定義，而為它們加入**帶版本的觀察層**。

本文採用前篇的任務契約 $\mathcal T=(x_0,\mathcal C,\mathcal E_0,\mathcal Q,\mathcal V,\mathcal B,\mathcal P)$。其中來源快照 $x_0$ 必須能追溯至來源版本；若外部工具另提供 $x_1$，這是新證據，而不能算成同一來源的純內部再理解。認知操作 $a_t$、底層資源路由 $\rho_t$、候選表徵 $r_t$、驗證事件 $v_t$ 和訓練參數 $\theta_u$ 均應具有獨立識別與時序關係。

這也意味著：DAS-LL 不把光譜理解為固定的「深度等級 1 至 10」。它是一個對不同觀察尺度成立的多維紀錄，而不是單一通用的智力分數。

## 3. 必須嚴格分離的六層物件

| 物件層 | 主要內容 | 可由什麼確認 | 不能直接推出什麼 |
|---|---|---|---|
| 來源層 | 原始文件、切片、資料集、版本、權利狀態 | 位元組雜湊、來源中繼資料 | 模型已讀過全文 |
| 事件層 | 接觸、檢索、前向、重構、反向、更新、驗證 | 執行儀表／可靠呼叫憑證 | 對任務產生正向影響 |
| 表徵層 | 候選、表示法、轉換、等價／橋接義務 | 輸出／狀態快照、可重播轉換 | 某特徵在權重中的唯一位置 |
| 計算層 | 模組、層、專家、工具、控制器、時間與成本 | 開放式模型遙測、工具紀錄 | 專家編號代表固定學科 |
| 參數層 | 檢查點、優化器、梯度與參數位移 | 訓練檔案、檢查點差異 | 一次更新即學得指定知識 |
| 能力層 | 正確性、泛化、保留、遺忘、失敗 | 預註冊外部測試與重測 | 全域理解已窮盡 |

這六層構成研究資料型別系統。每一層可以缺失；但缺失不得由另一層的數值冒充。

## 4. 來源同一性、粒度與時間

### 4.1 同一段文字不是同一個出現事件

定義來源身份為帶版本的對象：

$$
 s=(\mathrm{source\_id},\mathrm{version},\mathrm{content\_sha256},\mathrm{scope}).
$$

`content_sha256` 只證明對**同一個確切位元組序列**執行指定雜湊演算法得到相同摘要；它不保證作者、授權、事實性或語義相同。若 OCR、清理、分詞、截斷、翻譯或語義改寫更動位元組，必須建立新的產物與來源關係，不能暗中改寫原始來源的雜湊。

同一文件還可能包含多個資料切片：`slice_id` 指向特定版本、位元組區間或 token 範圍，並附分詞器版本。一個來源出現於兩個訓練批次，不等於兩次完整文檔閱讀；一個批次內的重疊切片，也不能簡單相加為兩份獨立知識。

### 4.2 來源關係採宣稱與證據分離

對於語義相似、同義改寫、摘要繼承與引用，本稿不以原始雜湊直接判定。同源判定可標為：`exact_bytes`、`declared_derivation`、`tested_equivalence`、`heuristic_similarity` 或 `unknown`。其中 `heuristic_similarity` 僅能作資料清理候選，不等於無條件認定兩個文件在邏輯上等價。

### 4.3 同一事件至少有三種時間

1. **發生時間** `occurred_at`：執行事件按系統紀錄的時間，不宣稱所有分散式節點的時鐘完全同步。
2. **入帳時間** `recorded_at`：事件進入帳本的時間，可晚於實際發生。
3. **來源可得時間** `source_available_at`：該來源、檢查點或外部證據何時被公開或可取得，不能以現在的知識倒填歷史。

對外部研究還需記錄 `effective_at` 或模型版本適用時段。當補登或撤銷既有事件時，增加新更正事件，保留原始時間與更正理由，避免造成「2026 年曾預先知道 2027 年結果」的歷史錯覺。這與目標 Frontier-Scaling-Lab 的追加式證據與 as-of 重播要求一致。

## 5. 學習事件的嚴格型別表

本文以 `event_type` 作第一級識別，並要求指標的分母與時鐘根據型別定義。以下型別是候選規約，並非聲稱所有封閉模型均可取得。

| 事件類型 | 原則性觸發條件 | 計數單位 | 學習推論限制 |
|---|---|---|---|
| `INGEST` | 來源被納入處理管線 | 已完成匯入事件 | 不表示被模型運算 |
| `PRESENT` | 來源片段正式提供給運算輸入 | 實際呈現片段 | 不表示每個 token 均被有效注意 |
| `RETRIEVE` | 外部記憶／資料庫返回可用來源 | 工具回傳事件 | 不表示模型參數包含此知識 |
| `FORWARD` | 可辨識的模型前向計算完成 | 前向操作及必要 token 量 | 不表示反向更新 |
| `REVISIT` | 控制器重新審視既有來源 | 帶同一來源版本的重讀操作 | 不保證新表徵 |
| `RECONSTRUCT` | 產生新表徵候選及關係憑證 | 候選轉換事件 | 不保證品質或正確性 |
| `DOMAIN_BRIDGE` | 提出跨域對應與橋接義務 | 映射候選 | 類比不是已證蘊涵 |
| `ROUTE` | 實際選擇計算資源或專家 | 路由決策及啟用資源 | 專家編號不是知識域名稱 |
| `VERIFY` | 固定版本的檢驗契約執行 | 外部／內部驗證運行 | 檢查覆蓋不代表完整真理 |
| `BACKWARD` | 對某個計算圖執行梯度反傳 | 完成的反向操作 | 不表示優化器已更新 |
| `OPTIMIZER_STEP` | 優化器處理一個更新步次 | 更新操作 | 不表示權重確實位移 |
| `CHECKPOINT` | 保存可識別的模型／優化器狀態 | 快照 | 不表示具新能力 |
| `USE` | 來源或表徵被具體任務引用／消費 | 可追溯使用事件 | 引用不保證影響決策 |
| `EVALUATE` | 任務能力測試與評分 | 測試評估 | 不等於訓練發生 |
| `CORRECTION` | 對先前帳目追加更正／撤銷 | 更正事件 | 不抹去原始歷史 |

計數不允許跨型別相加成「總學習次數」。例如 `RETRIEVE=3` 和 `OPTIMIZER_STEP=2` 沒有可加總的相同單位。需要總運算成本時，應使用獨立的 token、FLOPs、能量、延遲或費用模型，而非以事件數估算一切。

## 6. 事件圖與可審計的形式化結構

### 6.1 帶型別的事件圖

定義帳本為：

$$
\mathcal L=(\mathcal S,\mathcal E,\mathcal R,\mathcal K,\mathcal V,\mathcal G,\tau,\omega).
$$

其中 $\mathcal S$ 是來源與派生來源集合，$\mathcal E$ 是不可重用事件 ID 的有序事件集合，$\mathcal R$ 是候選表徵集合，$\mathcal K$ 是模型／優化器檢查點集合，$\mathcal V$ 是驗證憑證集合，$\mathcal G$ 是帶型別的來源—事件—表示—檢查點關係圖，$\tau$ 為時間與版本投影，$\omega$ 為可觀測性及證據狀態標記。

W3C PROV-DM 已提供 entity、activity、agent、derivation 與 influence 等溯源概念。[1] DAS-LL 不宣稱發明資料溯源；它增加的是適合 AI 深度注意力訓練的**事件型別、分母契約、神經觀察、驗證與因果限制**。尤其重要的是，`derived_from` 應由具體變換憑證支撐，不能因兩個來源同時出現在一個事件中便自動建立真實的因果邊。

### 6.2 事件先後與因果先後

對同一執行程序，局部事件可有單調序列號 $i$；跨工具或跨機器需另記錄 `run_id`、`parent_event_ids` 與時鐘誤差。`occurred_at` 的字面排序僅是觀察線索，不能代替真正的 happens-before 或可干預因果證據。

帳本的關係類型至少分為：`observed_input_of`、`produced_by`、`declared_derivation`、`verified_by`、`estimated_influence`、`causal_intervention_effect`。其中最後兩者必須附方法、條件、基線及不確定性，不得與 `observed_input_of` 混用。

### 6.3 事件去重與重播

事件唯一鍵採 `event_id`；在同一 `run_id` 重送同一事件時，具有相同事件 ID 與相同內容摘要者視為冪等重播，不可重複計數。相同事件 ID 而內容不同則是資料衝突，不得靜默覆寫。實際執行兩次相同操作仍應有兩個不同事件 ID，否則會被錯誤刪除。

## 7. 學習光譜不是一條單軸，而是帶未知值的向量

### 7.1 觀察窗口、型別與集合

令 $W$ 是預先指定的時間／模型檢查點窗口，$\mathcal E_W$ 是該窗口中符合事件完整性規則的事件，$\operatorname{ref}(e,s)$ 是事件 $e$ 明確關聯來源 $s$ 的關係。對事件類型 $k$ 定義：

$$
C_k(s,W)=\sum_{e\in\mathcal E_W}\mathbf1[\operatorname{type}(e)=k\land\operatorname{ref}(e,s)].
$$

上式只在記錄對該事件型別具有足夠覆蓋率時才應呈現為精確計數。若該類事件部分不可見，應改報已知事件下界與覆蓋狀態；不能把沒有紀錄當成沒有發生。

定義多維光譜：

$$
\Lambda(s,W)=(C_{\mathrm{present}},C_{\mathrm{retrieve}},C_{\mathrm{forward}},C_{\mathrm{revisit}},C_{\mathrm{reconstruct}},C_{\mathrm{backward}},C_{\mathrm{step}},C_{\mathrm{use}},V,R,N,\mathbf c).
$$

這裡 $V$ 表示獨立驗證的結果分布，$R$ 表示延遲評估的能力保留資料，$N$ 表示神經與路由的遙測及證據級別，$\mathbf c$ 表示運算、記憶、延遲、費用與人工介入成本；維度不可任意縮減為一個「理解分數」。對未提供神經網路內部資訊的封閉 API，$N$ 須標記不可觀測，而非填入零。

### 7.2 有效表徵與運算次數必須分開

可令 $Q_{\mathrm{valid}}(s,W)$ 表示在固定驗證契約下通過的可比較重構數量，$Q_{\mathrm{distinct}}$ 則表示根據預先指定等價準則的結構差異數量。二者不等價，因為新穎表徵可能錯誤，重複表徵也可能以另一種證明改善可檢驗性。

若希望導入有用的「探索效率」，應使用帶定義的比率，而非把深度序列直接編碼成越長越好：

$$
\eta_{\mathrm{reconstruct}}=\frac{\#\{\text{通過預註冊外部改進條件的重構}\}}{\#\{\text{實際提出的重構候選}\}}.
$$

當分母為零，輸出 `undefined` 或 `not_applicable`；當驗證契約改版，另建新版本的分母與分子，不能覆寫舊分數。

### 7.3 哪些比較不合法？

不同模型版本、不同分詞器、不同重讀單位、不同難度題目、不同來源時間窗之間的原始計數不能無條件比較。同一模型在 Batch A 裡一次前向處理 16 個樣本，與單樣本 Batch B 一次前向，不具有同等的逐來源運算量；反向傳播可能跨多步累積梯度。研究報表應同時保存 source occurrences、sample tokens、forward/backward 次數、估算 FLOPs 與運算模式。

## 8. 從資料來源到梯度：參與不等於影響

### 8.1 來源—批次—更新的關係

令 $B_u$ 是參與第 $u$ 個優化器步次的有效樣本多重集合；若梯度累積使用 $m$ 個小批次，$B_u$ 是這些微批次對該步次的集合，而不是僅最後一個微批次。定義來源參與步次集合：

$$
U(s)=\{u:\exists z\in B_u,\ \operatorname{lineage}(z,s)=1\}.
$$

因此 $|U(s)|$ 的語義是「來源參與了多少個優化器步次」，**不是**「來源使參數改變多少次」或「來源學習成功多少次」。若樣本混合多份來源，`lineage` 需顯示實際引入何種內容及各權重；無法辨識時應標示不確定。

### 8.2 梯度總量不能由來源頻率推出

對普通小批次損失均值，在滿足必要可微條件時可寫：

$$
 g_u=\frac{1}{|B_u|}\sum_{z\in B_u}\nabla_\theta\ell(z;\theta_u).
$$

但實際更新可能還有裁剪、混合精度、累積、正則化、動量、Adam 狀態、分散式同步等處理。即使來源出現次數已知，也不能唯一決定 $g_u$；即使知道某個樣本在原始梯度和式中有非零項，也不能直接推論最終參數位移由該樣本單獨造成。

對普通無動量與無衰減 SGD 可另寫：

$$
\theta_{u+1}=\theta_u-\eta_u g_u.
$$

在其他優化器下，$g_u$ 與 $\theta_{u+1}-\theta_u$ 的關係不再是上式。即使確實有非零參數位移，仍需外部泛化測試才能支持某項能力增益；若使用 LoRA 或凍結層，只有被開放更新的權重才有參數位移，但其他層的活化可能仍參與前向。

### 8.3 資料影響估計的研究位置

Koh 與 Liang 的 influence functions 對資料影響建立經典近似。[2] TracIn 使用檢查點與梯度訊號估計訓練資料影響。[3] 2025 年 ICLR 的研究已在大型模型預訓練上推進可擴展影響與事實追溯，但同時報告「因果影響」與「明確包含事實文字」的檢索不總相同。[4] 另一項 2025 年 EMNLP 研究在所研究的多種 LLM 設定中發現 influence functions 表現不理想，指出近似誤差與行為—參數關係等限制。[5]

因此 DAS-LL 可以保存 `estimated_influence`，但必須帶上方法版本、資料抽樣、參考問題、校準集及不確定性；**不能將特定來源的 estimated influence 數字直接當成該知識被存放的位置或真實貢獻百分比**。

## 9. 表徵歷程：同源重讀如何形成可檢驗的關係圖？

### 9.1 表徵節點

每個候選表徵應具有 `representation_id`、來源 `source_ids`、生成事件、操作類型、模型檢查點、所用工具、證據約束、驗證狀態及可選的狀態指紋。候選可以是符號式、圖結構、程式狀態、自然語言詮釋、證明義務或潛在表示。對無法匯出潛在狀態的封閉模型，僅得記錄對外可見的操作及輸出，不可宣稱完成內部表徵全貌重建。

### 9.2 同一來源下的三種關係

* **深化關係**：維持表示語言及問題域，但新增受檢查的約束或局部推論；例如重新發現被忽略的不變量。
* **重組關係**：以不同載體表示同一待解問題，需提供原條件的保留測試；例如將代數表示轉為有限搜尋。
* **跨域關係**：提出由外部知識域到目標域的對應；需另記映射前提與橋接驗證，不可把相似性視為定理。

記錄 `parent_representation_id` 並不能使新候選自動成為舊候選的有效延伸。有效性必須由獨立的檢查事件支持。

### 9.3 表徵相似性與跨版本比較

CKA 等表示相似度工具可用於比較模型不同層或檢查點的表示，但度量結果依資料樣本與使用方式而定，不是思想深度、知識同一性或概念因果來源的直接測試。[6] 若模型結構、分詞器、數據分布或檢查點不同，應事先定義可比性及樣本群；對輸出相同而隱狀態不同的情況，使用表徵相似度也不自動決定哪一個更正確。

## 10. 神經網路聯動：遙測、估計與介入的三層證據

### 10.1 可記錄但不保證語義的遙測

若研究者具有開放權重與運算存取，建議記錄：層級／模組 ID、路由器版本、活化範數、梯度範數、top-$k$ 專家與權重分布、專家負載、檢查點 ID、控制器操作及各模組估算運算量。若因記憶／隱私限制採樣，只能回報採樣覆蓋率；不能把未採樣事件當成零。

模型內部專家、神經元或注意力頭不一定對應固定概念。即使某模組在數學題中反覆活化，也不能由此得出它就是「數學理解神經元」。對注意力權重作解釋的研究已有實質爭論：有研究指出權重經常不能可靠代表輸出因果解釋，也有後續工作強調適切的解釋定義和控制實驗的重要性。[7–8]

### 10.2 推估級聯動

當研究者以訓練梯度、線性探針、表徵相似度或資料影響估計推論來源與模組關係，結論應標為 `estimated`，附上信賴區間、模型及假設。探針可能學會與任務相關但非因果的訊號；神經活化和輸出相關也可能只是共同上游條件造成。因此，「顯示聯動」不能被自動升格成「導致習得」。

### 10.3 介入級聯動

更強的因果研究可設計在相同來源、模型、隨機種子、任務契約和成本配對下，對特定模組做受限的 activation patching、消融或訓練資料排除，檢查外部輸出或驗證結果的反事實變化。ROME 等研究提供可對局部運算進行因果追溯與編輯的先例。[9] 但介入效果通常是**相對於選定測試分布與介入方法**的局部結論，不代表完全定位一個概念的全部存放位置；對分布外任務與長期維持仍須重新測試。

### 10.4 關鍵的權限限制

如果只提供黑箱 API 回應，DAS-LL 可以記錄提示、模型標籤、可見工具事件、輸出、外部測試與費用；不允許假稱已取得梯度、真實 MoE 專家選取或精確權重變化。若供應商更動底層模型而未公開檢查點，跨日的「相同模型」比較也需標為不確定。

## 11. 神經資訊與學習資訊的交叉識別

把一段資訊 $s$ 的事件集合記作 $E_s$，它對應的某層記錄 $H_s$，以及經預先定義的測試後得到的任務效用 $J_s$。可能存在以下四種組合：高接觸／高正確、高接觸／低正確、低接觸／高正確、低接觸／低正確。即使持有完整的 $E_s$，也不能自動決定後續 $J_s$；需考慮模型先驗、資料重複、其他來源、任務難度及訓練次序。

進一步地，同一個神經網路可能以分散式參數表示多項概念，而相同概念也可能由不同的激活子空間支持。跨版本比較應將「表示相似」、「行為相近」、「可由同一干預影響」與「來源因果貢獻」分開記錄。

**最強的合理主張**不是「我們已經看見 AI 心中所有知識」，而是「在指明的模型、來源與實驗條件下，某資料與某計算事件具有可追溯關係；在特定反事實比較中，某介入引起了可量測的效用差」。

## 12. 保留、遺忘與再次學習的時間維度

Toneva 等人研究的 example forgetting events，將某例由正確變為錯誤視作可以觀察的遺忘事件，說明學習中的個別樣本表現可能反覆變化。[10] 在 DAS-LL 中，若模型於檢查點 $u$ 答對、於 $u+1$ 答錯，可記錄行為層的 `forgetting_observed`；它不必然表示底層知識已完全消失，亦可能由取樣差異、推論策略、輸出解碼或任務改變造成。

形式化地，對固定的測試器版本與評估條件 $q$，定義通過指示值：

$$
A(q,u)=\mathbf1[\mathrm{Verify}(q,\theta_u)=\mathrm{pass}].
$$

一次行為遺忘事件為 $A(q,u)=1$ 且 $A(q,u+1)=0$。若測試器改版，兩次結果不能直接構成此事件；若評估具有隨機性，應以重複取樣與置信區間而非單次跳變立論。對持續學習，應另記資料回放、參數更新、能力重測與重新獲得通過的事件；不能把舊題再次答對自動歸因為「再次訓練」。

## 13. 五項條件性命題與反例

### 命題 DAS-F05-P1：相同事件計數不唯一決定參數變化

**命題。** 在一個允許不同梯度值的訓練系統中，兩個運行可以具有相同的資料呈現、前向、反向與優化器步次計數，卻具有不同的參數位移。

**反例與證明。** 令普通 SGD 初始 $\theta_0=1$、學習率 $\eta=0.1$，兩個運行都執行一次前向、一次反向、一次更新。運行 A 的樣本梯度為 $g_A=0$，故 $\theta_1^A=1$；運行 B 的樣本梯度為 $g_B=2$，故 $\theta_1^B=0.8$。所有上述次數相同，位移卻不同。證畢。這還未處理長期正確性，故更無法由次數推出學習成功。

### 命題 DAS-F05-P2：僅有相同外顯輸出不能唯一識別內部歷程

**命題。** 若輸出映射不是對全部可達內部狀態的單射，則存在兩個不同內部狀態具有相同輸出。

**證明。** 非單射的定義即存在 $h_1\ne h_2$ 而 $f(h_1)=f(h_2)$。例如 $f(h)=h^2$，$h_1=1$、$h_2=-1$。證畢。對真實神經網路，此命題只提示不可識別的可能性，不證明每個架構必然發生特定兩態。

### 命題 DAS-F05-P3：溯源可達不保證因果效果

**命題。** 在缺少獨立因果限制的情況下，某來源可由帳本路徑追溯到某個輸出，並不蘊涵移除來源會改變該輸出。

**反例與證明。** 設系統從兩份相同資訊 $s_1,s_2$ 同時檢索，輸出只使用 $s_2$ 的已驗證值。日誌把兩者都列為候選來源，但移除 $s_1$ 並不影響輸出。又或者模型完全忽略兩者而由內部預設產生同一結果。故路徑可達不足以保證反事實影響。證畢。研究者必須額外建立依賴或介入檢查。

### 命題 DAS-F05-P4：在完整度不明時，觀測計數只提供下界

**命題。** 若每個有效觀測事件確實對應一個真實事件，且實際事件可能有未觀察的部分，則某型別觀測事件數不大於真實事件數；然而不知覆蓋率時，不存在僅由觀測數可推得的有限一般上界。

**證明。** 觀測集合包含於真實事件集合，故基數不大於後者。對任一觀測數 $m$，可構造包含 $m+n$ 個事件但只記錄 $m$ 個的系統，$n$ 任意大，因此不存在僅由 $m$ 決定的有限上界。證畢。若日誌會產生虛假事件或重複事件，連下界假設也會失效，須先驗證事件真實性與冪等規則。

### 命題 DAS-F05-P5：雜湊鏈的歷史完整性不等於事件真實性

**命題。** 在雜湊函數具備適當抗碰撞性、首個可信錨點與鏈驗證密鑰／規則不被旁路的條件下，事後變更已鏈接的歷史紀錄而不更新後續鏈節，會使鏈檢查失敗；但通過鏈檢查並不能證明原始事件內容真實。

**證明。** 若後續鏈節將前節摘要納入其輸入，改變任一已鏈接紀錄會改變其預期摘要並造成後續不一致，除非破壞雜湊安全假設或替換可信錨點。然而記錄者完全可以在建立鏈之前寫入一條假事件；該假事件依然能取得合法摘要與有效鏈。證畢。外部簽章、硬體錨定和獨立驗證可提高證據強度，但仍不能將溯源完整性等同於科學真實性。

## 14. 最小可操作資料規約

### 14.1 共同欄位

每筆事件至少應包括：`schema_version`、`event_id`、`run_id`、`sequence`、`event_type`、`occurred_at`、`recorded_at`、`model_checkpoint_id`、`source_ids`、`observation_level`、`evidence_state`、`parent_event_ids`、`payload`。若類型不適用於某欄位，允許明確的 `null` 並附原因；不得自動生成一個不存在的模型檢查點。訓練事件還應保存資料集版本、分詞器／切片版本與 optimizer 配置索引，而不是把整個受限制模型內容直接附在事件中。

### 14.2 觀察性與證據狀態

* `observation_level`: `direct`、`derived`、`estimated`、`unobserved`、`not_applicable`。
* `evidence_state`: `synthetic`、`observed`、`inferred`、`unresolved`、`retracted`。

同一事件的 `observation_level=direct` 只表示該事件在指定儀表中直接觀測，並不蘊涵對其認知效果的直接觀察。`evidence_state=synthetic` 明確排除把樣本記錄當成真實模型性能。

### 14.3 Schema 和 JSONL 的責任分工

`data/das_f05_event_schema.json` 提供 v0.1 的基礎結構與欄位約束；`data/das_f05_synthetic_events.jsonl` 僅提供合成、可重播事件。JSON Schema 能檢查欄位格式和部分型別條件，無法自動驗證跨事件依賴、梯度真實存在或遠端模型是否誠實回報，故需另有跨行與執行環境測試。

### 14.4 合成記錄片段

以下截取概念性的兩個事件，完整測試資料另置於系列壓縮包中：

```json
{"schema_version":"0.1","event_id":"syn-e03","run_id":"syn-run-01","sequence":3,"event_type":"RECONSTRUCT","occurred_at":"2026-11-09T13:00:03+08:00","recorded_at":"2026-11-09T13:00:03+08:00","model_checkpoint_id":"syn-ckpt0","source_ids":["syn-math-source-v1"],"observation_level":"direct","evidence_state":"synthetic","parent_event_ids":["syn-e02"],"payload":{"representation_id":"syn-r2","parent_representation_id":"syn-r1","operation":"recompose","verified":false}}
{"schema_version":"0.1","event_id":"syn-e04","run_id":"syn-run-01","sequence":4,"event_type":"VERIFY","occurred_at":"2026-11-09T13:00:04+08:00","recorded_at":"2026-11-09T13:00:04+08:00","model_checkpoint_id":"syn-ckpt0","source_ids":["syn-math-source-v1"],"observation_level":"direct","evidence_state":"synthetic","parent_event_ids":["syn-e03"],"payload":{"verifier_id":"syn-verified-logic-v1","outcome":"pass","test_contract_id":"syn-contract-v1"}}
```

這裡 `verified=false` 是產生候選時的即時狀態；後一事件可證明特定版本驗證器隨後回報 `pass`，但不可在原事件中偷偷覆寫為 `true`。若驗證器存在漏洞，補記更正事件及新版本測試，而不是清除舊歷史。

## 15. 合成重播案例：相同資料，多種計數

考慮三份虛構來源 $s_m$（數學敘述）、$s_p$（程式狀態）與 $s_h$（跨域類比），其中 $s_m$ 在推論期間經歷展示、重新審視與重組，隨後被一份小型訓練批次引用；$s_p$ 僅被檢索並用於程式除錯；$s_h$ 只提供尚未證明的跨域映射候選。

預期必須發現：

1. `RECONSTRUCT` 候選數與 `VERIFY(pass)` 數可以不同；驗證通過不會事後自動增加前向或反向次數。
2. `RETRIEVE(s_p)` 不能進入 `OPTIMIZER_STEP(s_p)` 的計數；一個來源被檢索不表示參數更新。
3. 同一 `optimizer_step_id` 可以由多個 `BACKWARD` 微批次彙整；它仍是一個優化器步次，而非按微批次乘成多次。
4. `DOMAIN_BRIDGE(s_h)` 在沒有橋接驗證時只能算候選，不可計入有效跨域結論。
5. 若儀表停止記錄 `ROUTE`，專家調用量應變為未知，而不是零。
6. 對同一事件 ID 的重複投遞，帳本以相同內容執行冪等去重；相同 ID 不同內容應拒絕。

附屬 `validation/das_f05_sanity.py` 只驗證這些合成事件及計算性質，並附一組預期會被拒絕的錯誤事件。它不能證明神經網路在現實環境中的某種知識存放或認知能力。

| DAS-LL08 | 表徵重構候選數 | `RECONSTRUCT` 候選 ID 數 | 不等於有效新知 |

| DAS-LL10 | 同域深化比例 | 經確認同域候選／可分類重構候選 | 分類器有不確定性 |
| DAS-LL11 | 跨域橋接候選數 | `DOMAIN_BRIDGE` 提案數 | 類比不等於橋接成功 |
| DAS-LL12 | 跨域橋接驗證率 | 通過橋接義務候選／已正式驗證候選 | 不使用無法證明者當失敗 |
| DAS-LL13 | 專家路由可觀測率 | 有內部路由憑證的調用／應記錄調用 | 封閉模型標不適用或未知 |
| DAS-LL14 | 路由負載分布 | 專家啟用次數／全部已觀測啟用 | 不推測學科語義 |
| DAS-LL15 | 表徵跨檢查點可比較率 | 滿足同基準契約比較數／擬比較數 | 不把 CKA 當正確性 |
| DAS-LL16 | 因果介入可識別率 | 有受控介入且符合前提的主張／提出之因果主張 | 需公開比較設計 |
| DAS-LL17 | 訓練遺忘事件率 | 固定題集正轉錯次數／符合重測條件對數 | 隨機性與題庫污染揭露 |
| DAS-LL18 | 再學習保留率 | 再學後延遲測驗通過項／符合測驗項 | 與單次再答對分開 |
| DAS-LL19 | 事件溯源完備率 | 必要欄位及父事件存在之紀錄／應記錄事件 | 完備不等於真實 |
| DAS-LL20 | 單位有效重構成本 | 全任務成本向量／有效外驗重構數 | 分母為零時不定義；公開失敗成本 |

候選名稱與數值口徑是本稿的初步規範，不得推定既有模型具備這些指標的任何實測能力；資料目錄可在第六篇研究完成後才以獨立 JSON 註冊，並與第三、四篇的 DAS-R／DAS-L 指標平行保存。

## 17. 實驗設計：如何把帳本從「漂亮的記錄」變成有用的研究工具？

### 17.1 先檢查觀察系統能否正確分類

建立受控小型模型，人工注入已知 `PRESENT`、`BACKWARD`、`OPTIMIZER_STEP` 及 `VERIFY` 事件。檢查去重、階層時鐘、微批次累積、關係型別及版本回放。如果連基本事件都無法區分，所有高階的理解光譜指標都沒有可信分母。

### 17.2 控制不同資訊路徑的重複學習

對來源 $s$ 設置預先註冊的低／中／高接觸條件，保持總訓練 token／算力、樣本多樣性與評估資料不受污染。對照無 DAS 控制、普通重試、帶重構操作、帶重新學習排程的多組模型。使用延遲測試區分短期重新表達與長期知識保留；報告任務能力、成本、錯誤回復與遺忘，而不是只比較接觸次數。

### 17.3 反事實影響實驗

在可行的小模型上，隨機決定某個已審核資料族是否進入訓練，或對同一來源使用不同表示／路由策略，保留可重訓的檢查點與種子。比較目標結果與未見題的表現，才能對特定資料的因果貢獻提供較強、但仍帶條件的估計。若需要大量昂貴重訓，則可用梯度影響近似作探索排序，不能把近似冒充真正的反事實試驗。[2–5]

### 17.4 在神經介入中確保成本與測試隔離

對某模組施加消融，應以相同計算資源的隨機模組介入及零介入作比較；檢查對照是否破壞其他能力、是否只是延長推論時間，以及所選模組是否因測試資料洩漏而被挑出。不可先觀察測試答案後任意挑出最有利的層或指標，再對同一資料聲稱獨立有效。

## 18. 風險與治理：可追蹤不等於應無限制保存

DAS-LL 可能意外保存提示詞、用戶資料、版權文本、敏感專案、訓練樣本以及神經梯度。梯度本身在特定攻擊條件下可能洩露訓練資料，已有相關實證研究。[11] 因此不能把「更完整的學習光譜」等同於「永久保存全部原始資料與梯度」。

最低限度的控制包括：對來源採最小可用標識、將原始敏感內容與事件索引分層儲存；只在合法授權與研究必要時收集模型內部梯度；限制存取權限與保存期限；建立撤銷與更正記錄；公開報告只發布足以重算指標的聚合值及其覆蓋條件。當研究者為保護隱私選擇不存資料，應在統計報告留下 `redacted` 或 `unobserved`，不應捏造精確數字。

與 Frontier-Scaling-Lab 整合時，還需採用該庫現有的來源日期、紀錄日期、證據等級與追加式資料原則。用於研究測試的合成數據必須顯示 `synthetic`，不進入外部能力榜或實際觀察統計；任何直接上傳 GitHub 的學習事件要先經資料權利與機密檢查。

## 19. 可反駁的研究假說與負結果

**H1（可觀察性改善）。** 在有內部儀表且事件型別固定的設定中，DAS-LL 能降低將檢索次數誤列為訓練更新次數的分類錯誤。如果既有成熟追蹤工具已能達到相同效果，則本框架可能只具整合規範價值。

**H2（表徵歷程的額外解釋力）。** 在控制總前向／反向算力、模型參數量、資料量與問題難度後，增加經驗證的表徵轉換紀錄，能否比單純記錄 token 及 optimizer steps 更準確預測下一次同域／跨域任務的表現？若不存在額外預測價值，則不支持其作為新學習能力指標。

**H3（介入歸因的嚴格性）。** 在受控小模型中，介入式神經聯動主張能否相較注意力熱圖相關性，更好地預測外部行為變化？若介入結果對隨機種子、任務集或模組選擇高度敏感，則只能保留局部發現。

**H4（總成本效益）。** 帳本支援的再學習排程，在高失敗代價任務上可能節省人工重述和重試成本，但在簡單任務上可能增加儀表與儲存負擔；必須報各成本分量、信心區間與實際負結果。

**H5（跨版本可重播性）。** 同一事件流在相同 schema 和分析規則下能否重現同一計數；當 schema 更新，是否能以明確遷移規則保持舊指標可追溯？若需要大量人工補猜事件來源，應降低系統成熟度，而不是暗稱具完整自我記憶能力。

## 20. 研究限制與必須保留的未知

1. **事件覆蓋不足**：不存在訓練儀表的系統無法回溯權重訓練史；即使有檢查點，也可能無法重建全部資料參與。
2. **知識的分散表示**：不存在已證明普適的「每項知識 → 唯一神經元」映射；同一功能可能由不同子網路實現。
3. **因果歸因困難**：樣本重複、順序交互、梯度近似及替代來源會使觀察相關不等於反事實效果。
4. **資料同一性不完整**：原始位元組雜湊不能解決翻譯、摘要與概念重述的語義等價問題。
5. **驗證契約有限**：形式化數學與程式可有較強的外驗訊號；哲學與開放式理論任務不一定存在完整真值驗證器。
6. **量測改變系統**：詳細記錄神經運算可能影響訓練效能、記憶體負載及隱私風險，須測量觀察者開銷。
7. **指標善化問題**：模型可能學會增加 `RECONSTRUCT` 次數或裝飾表徵圖，卻沒有任何外驗收益；不可將事件量本身當成獎勵函數。
8. **合成案例有限**：附帶程式只驗證形式／資料規則，不能代替真實模型、獨立資料分割與跨種子重複實驗。

## 21. 對第六篇的明確輸出接口

本稿輸出一套可供最終驗證篇使用的事件規約：來源 ID 與版本；事件型別與去重鍵；認知路由與專家路由的分離觀測；表徵圖與驗證憑證；梯度、更新與權重位移分別記錄；保留與遺忘的延遲測試；受權限限制的神經遙測；可分層呈現的成本與人工重述負擔。

第六篇應把這些資料與獨立能力測試結合，建立清楚的**因果比較、成本邊界與停止宣告**，並在所有指標無法量測時勇於保留 `unknown`。若研究結果顯示 DAS-LL 只是改善可觀測性，而沒有改善模型學習，仍是可發表的工程／方法論結果；但不得稱其證明深度注意力的效能優越。

## 22. 結論

AI 的學習歷史不應只被簡化為「曾經看過多少 token」或「優化器跑過多少步」。同一份資訊可以被檢索、推論、再提取、重構、跨域連結、反向傳播或在不同檢查點再次使用；這些事件具有不同的計算機制、觀測能力、時間尺度與因果含義。

DAS-LL 主張建立帶來源、時間、版本、事件型別、表徵關係、神經遙測及外部驗證契約的學習光譜，以便研究者追溯模型如何處理已經接觸的資訊，並評估重新學習是否值得其成本。但本稿同時證明：**來源曾參與運算不蘊涵它具有特定因果影響，參數確有變化不蘊涵模型形成穩定知識，外顯表現正確也不蘊涵全部內部歷程已被識別。**

因此，深度注意力學習的核心不只是增加資料重讀與權重更新，更是建立一套有能力追問自身訓練和表徵歷史、又懂得承認不可觀測部分的研究紀律。

**能追溯的不是全部理解；但不肯區分自己究竟觀察了什麼，就無從嚴格研究理解如何改變。**
