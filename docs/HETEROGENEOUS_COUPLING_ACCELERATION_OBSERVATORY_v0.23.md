## 2. 研究契約、證據與歷史

一個 study 鎖定註冊收據、觀察起迄時間、資料分類。每 frame 是同一任務／組織／區域情境下的 topology、coupling 或 absorption，參照 GICCF 的領域 ID、成果契約、單位契約、模型假設 SHA-256、貨幣最小單位與最低公開群體數。模型契約應明定可比較座標、層狀態的詞彙、邊全集、抽樣框、合法性、成本及時間量綱。哈希只是參照，程式不獨立檢查其實質內容或合法性。

每次事件為指定 frame 完整快照，須在觀察窗結束之後出具，且發生時間不晚於公開時間、不晚於 FSL 錄入時間。同 frame 的修訂須直接指向唯一前一版；改變契約或模型假設應另建 frame，而非用修訂宣稱現實已改變。strict_known_at_time 依發生、公開及錄入截止；retrospective_reconstruction 可使用當時已公開但後來錄入的材料。日期截止按 UTC 日末；未指定時區的時戳不接受。

資料只有 synthetic 或 observational；合成輸出獨立放 synthetic_scenario，沒有外部來源 URL 或評審身分。觀測主張需要 HTTPS 證據來源；repeatable_test 以上需工件哈希，獨立級另需評審參照。provider_claim、provider_demo、unobserved 留收據但不生成數值模型結果。無事件、未達證據門檻的 frame 為 unmeasured，不為零。所有可計算結果仍是由記錄輸入生成的條件結果，不是外部核實、因果或真實部署認證。完整資料結構會驗證，包含截止日後尚未可見的修訂；不讓未來修訂影響先前數值重播。

## 3. SET-M：有限時代拓撲

### 3.1 異質狀態纖維與方向性

nodes 分領域與完整八層狀態。各座標是依契約定義的字串型別值或 null，不把 K 到 G 強行放在共同數值刻度。跨域轉換必須有具體操作契約。transitions 的 allowed/unknown/blocked 為模型內邊狀態；若有歷史、權限、消耗或不可逆效果，應先展開到不同節點，不許任意拼接不同時間快照。圖中未列邊表示不在本次註冊候選全集，不能推出世界中永遠不可能。

在同一版本、固定非負可加成本下，分別計算 allowed 邊的可達集合及 allowed+unknown 邊的可能可達集合。前者為模型內最小開鄰域（以正向可達定義 Alexandrov 拓撲）；不能當成地理、時間或文化距離。unknown 不當作 blocked。optimistic_lower 將未排除的邊納入且未知成本以非負下界零計；known_cost_upper 只走合法且成本已知的邊。前者是條件下界，不是已知成本為零；後者 null 表示無已知成本路徑，並不排除可達性。不能由可達性生成部署機率。不同版本的路徑成本不可直接串接。

### 3.2 AND 資格與共同資源

facts 初始 present/unknown/absent；rules 為聯合前提及結論。只在有限、無消耗、無撤銷的累積資格模型下計算最小閉包：確定圖只以 present 事實及 allowed 規則開始；可能圖加入 unknown 初始事實及未排除規則。不得將聯合前提拆成 OR；閉包只代表條件資格，不代表已實施行動。

resources/ plans：每個資源有固定容量，所有方案同時、排他、可加總使用；需求逐一明列，零與 null 分開。已知部分合計超過已知容量則不可能同時執行，即使其他需求未知；每個單項可行不推出聯合可行。共同資源模型不涵蓋動態預算、時段競爭、複用或規模經濟。

activities：固定 DAG、全部活動必要、允許無限並行、非負工期。長度由前置最大完成時間加本身工期取得；周期依賴拒絕；工期缺失不補零。此 makespan 在共享設備、返工、排程和其他約束下至多為對照模型。

joint_coverage：同一固定共同母體的兩個邊際及交集。Fréchet 界為 max(0,a+b−N) 到 min(a,b)，保留未知邊際時的較寬界。已知交集須與邊際相容。不存在跨不相容母體的交集估算；此界不是信賴區間。未建立全域排序，亦未實作任意序數向量偏序或組成效果估計，原論文之命題仍可單獨重播。

## 4. CFA-M：跨域耦合與受限回饋

coupling frame 只容許兩個明定領域，所有單位及共同週期由契約指定。pipeline 以同單位、固定串聯、無損耗容量假設計算 min(capacities)；單件固定串行週期另取基線與候選耗時總和的比率。吞吐量與單件時間分開。多層驗收使用同一候選 cohort 的巢狀計數，分別計算條件比率與末層聯合比率；不假設階段成功獨立。若缺值或不符合模型假設，相關結果為 null。模型不會對真實實驗自動認定安全、法律或物理量產品質。

linear_feedback：沿用 ASTT-08 T4 固定二維無外部新增輸入、無延遲非負存量模型。自留係數 a,d∈[0,1)，跨域 b,c≥0，整數基點表示（10000=1）。精確比較 bc 與 (1−a)(1−d)，分為次臨界、臨界、超臨界。方向收斂附加條件為 b,c>0 且 a+d>0（非零正初態及固定模型仍為必要背景）。沒有參數或假設不成立則不算。這不是從同時增長估計 b,c。

bounded_stock：沿用 ASTT-08 T5，K 下一期=(1−δ)K+min(γK,C)，固定無外部新增存量，0<δ≤1、γ≥0、C>0。以 Fraction 重播有限期（至多 60 期），γ>δ 時的唯一正平衡 C/δ，零初態仍吸收；γ<δ 趨零；γ=δ 存在連續固定點區間，從初值的極限為 min(initial,C/δ)。positive_equilibrium 欄位專指超臨界唯一正平衡；等號情況以 limit_from_initial 表達，不宣稱沒有正固定點。

cycles：按時序列候選產物的輸入輸出、驗收、實際使用、外部依賴、對照設計收據，以及安全、授權、資格和計畫／模擬／實際記錄型別。只把相鄰週期輸出等於後一輸入、兩期閘門通過、實際使用與外部依賴收據存在的情況標為 candidate_recorded_link；這仍未核實因果歸因、增益與必要支撐域閉合。合成週期永遠不得獲此標記。對照設計收據不等於已完成對照試驗，不估計跨域因果係數。FSL v0.17 原兩道門檻維持原狀。

## 5. CAT-M：文明吸收與非同步生活時間

queue：固定群組、等期長度、事件而非任意人口數。每期有期初積壓、到達、復發、合格承接、其他退出、容量及期末積壓。已知完整流量守恆，連續期末與期初一致，承接不超容量。當假設為 work_conserving_partitioned、無復發/其他退出且從首期資料完整，計算理想無摩擦池化對照與分區缺口；中途缺值後不可假造池化路徑。實際資料一般使用 accounting_only。期末積壓×固定期間為離散事件日，不是精確個人等待天數；未完整觀測時總暴露與峰值 null，另外保留已知期間暴露下界。

matching：固定期限、相同契約下的匿名同質群組與可接受目的地工作槽（各組非重複且完整可拆分），容量是人數／槽數。用整數最大流計算 allowed 邊的下界及未排除邊（含未列交叉組合，視為 unknown）的上界。任何群數或槽數未測即不推估最大流。這是群組內所有配對一致可行的條件模型，不是逐人評等、聘用保證、配對決策或長期均衡。只接受基於合意選擇的匿名、合法群體相容性資料；不得推測敏感屬性。

standardized_budget：單一明示、標準化預算情境，非將群體總現金流直接推成每個家庭。初始現金與已收到流入、到期流出之完整期末前綴，給出最低一次性期初橋接額。未收到款項不算流入，若期內先後順序重要需改用細時間粒度。比較所得與實際所得另計帶正負差額及逐期正缺口；其基準不是已證反事實。未測時不補值。制度保障或福利的實體供給另至 v0.24。

followup：同一固定 cohort，首次承接期限、持續觀測長度分立；持續成功定義為在首次期限內承接且持續通過事先標準，故須屬首次成功；首次失敗必屬此定義下持續失敗。兩個 endpoint 的成功、失敗、未知及抑制格分開，未達充分追蹤期不可擅填失敗。計算缺值識別界而非信賴區間，持續上界不超首次上界。不能由職位終點推出路徑生活狀態或因果效果。

公開觀測聚合最小正值格預設至少十個單位、可提高，包含基本補數與守恆反推檢查；這不保證匿名性或差分隱私。所有群組識別符應為合成或真正聚合 ID，不記錄個人資料，實際出版前須審計小群體、跨表、跨期、異質性及同意。制度承接不可把人強制放進不接受的工作。模型不處理真實個人財務或福利建議。
